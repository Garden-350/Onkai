# 低速のバグの直し方 と 新しい演出「下から戻る」（11/18）

## 1. 低速がおかしい原因（1 か所だけ）

ゲームの `Gimmick.cpp` の `Progress` で、カッコの位置が 1 つずれています。

```cpp
// 今（まちがい）
return 1.0f - (Scroll(arriveTime) - Scroll(now) / duration);
// 正しい
return 1.0f - (Scroll(arriveTime) - Scroll(now)) / duration;
```

今の書き方だと、割り算が `Scroll(now)` だけにかかってしまいます。そのため、ノーツが奥の端にはりついたまま判定の時刻が来て、MISS になっていました。
（演出が 1 つでもある譜面だと、低速の所以外でもずれます。演出が無い譜面は、別の式を通るので今まで通りです。）

ついでに、その 2 行上の `duration = 0.00001f;` も `0.0001f` にそろえてください（0 が 1 個多い。動きには関係なし）。

## 2. 新しい演出「下から戻る」（type "rise"）

始まりの瞬間に、見えているノーツが判定円の少し下へ集まり、勢いよく元の位置へ戻ります。そのあとは普通に落ちてきます。
（今までの「逆走」も残してあります。）

しくみ：判定円からの距離に倍率をかけるだけです。倍率は `from`（-0.3 = 判定円の少し下）から始まり、`end` までに 1（元の位置）へ戻ります。最初が一番速く、だんだんゆっくりになります。
判定円の所（距離 0）は倍率をかけても 0 なので、**叩く時刻の見た目はずれません**。

### ゲーム（自分で書き写している分。足す所だけ）

	Speed,
	Rise,		// 下から戻る：始まりの瞬間、見えているノーツが判定円の下に集まり、勢いよく元の位置へ戻る
};
```

```

`namespace Gimmick` の中、`InView` の上に 2 つ：

```cpp

	float DisplayProgress(float spawnTime, float arriveTime, float now);
	// 今の「距離の倍率」（下から戻る の間だけ 1 以外）
	float DisplayScale(float now);
```

**Gimmick.cpp**（`Progress` の下に足す）

```cpp
	float DisplayScale(float now)
	{
		float s = 1.0f;
		for (const auto& e : s_Events)
		{
			if (e.type != GimmickType::Rise) continue;
			if (now < e.start || now >= e.end) continue;
			float u = (now - e.start) / (e.end - e.start);				// 0〜1
			float k = 1.0f - (1.0f - u) * (1.0f - u) * (1.0f - u);	// 最初が一番速く、だんだんゆっくり
			s *= e.from + (1.0f - e.from) * k;
		}
		return s;
	}

	float DisplayProgress(float spawnTime, float arriveTime, float now)
	{
		float p = Progress(spawnTime, arriveTime, now);
		return 1.0f - (1.0f - p) * DisplayScale(now);	// 判定円からの距離を倍率でのばす・縮める
	}
```

`PointVisible` の `if (frac > 1.0f || frac < -kBelowLimit) return false;` のすぐ下に 1 行：

```cpp
		if (frac * DisplayScale(now) < -kBelowLimit) return false;	// 下から戻る で、見える所より下にいる
```
