# 改善点まとめ（10/30 時点）

企業フィードバック（10/10）を受けてからの改善を、フィードバックごとにまとめた。後半は、フィードバック以外の改善（遊びやすさ・速さ・不具合）。

状態の見方
- **済**：作って組み込み、動作を確認したもの
- **組み込み済み・要確認**：組み込んだが、直しや確認が残っているもの
- **修正案あり**：直し方は出したが、まだ組み込んでいないもの

---

## 1. フィードバックへの対応

### 「エフェクトを追加しすぎない」→ 量より「置き場所」で解決（#2）

軸は「ノーツと判定まわりは絶対に見やすく保つ。演出はその外側に置く」。

| 工夫 | 中身 | 状態 |
|---|---|---|
| カメラを 2 層に | 背景・敵（World）とレーン・ノーツ（Playfield）を別のカメラで描く。目線を動かす演出は背景側だけに効き、ノーツの位置はずれない | 済 |
| 攻撃の光はレーンを横切らない | 判定円から敵へ飛ぶ光は、左手のレーンは左へ、右手は右へふくらむ曲線で飛ぶ | 済 |
| 盾は下ほど薄く | レーンに重なりやすい盾の下の方ほど薄くする（外枠・ヒビ・破片の全部） | 済 |
| 破片はレーンへ来ない | 割れた破片は必ず上と奥（敵の方）へ飛び、落ちてくる前に消える。塗りつぶさず線だけ | 済 |
| 演出は一瞬・加算 | 白い光 0.12 秒、揺れ 0.25 秒、盾が消えるまで 0.15 秒。加算合成で後ろを隠さない | 済 |
| 波紋の出しすぎ防止 | 盾ではじいた時の波紋は 0.1 秒に 1 つまで。攻撃の光も同じレーンから 0.12 秒に 1 つまで | 済 |

### 「コンボなどで背景に変化を」＋「緑の球をペンライトに」（#3・#8）

コンボでボルテージ（盛り上がり）が上がり、世界が変わる。

| 変わるもの | 中身 | 状態 |
|---|---|---|
| ボルテージ（HypeMeter） | コンボ 10 / 30 / 60 / 100 で段階が上がる。上がる時は速く、ミスの後はゆっくり下がる | 組み込み済み・要確認（打ち間違いの修正あり） |
| 観客のペンライト | 意味のない緑の球を、客席のペンライトに。ボルテージで数が増え、色とりどりになり、拍に合わせた振りがそろっていく | 組み込み済み・要確認（打ち間違いの修正あり） |
| スポットライト | ボルテージが低いと暗く静か、上がると今までの明るさに | 組み込み済み |
| 流れてくる四角 | ボルテージが上がるほどたくさん流れる | 組み込み済み |

### 「ロングを押している間が暇」→ ロングの盾（#5・コンセプトの核）

| 工夫 | 中身 | 状態 |
|---|---|---|
| ロングの盾 | ロングの間、敵が盾を張る。曲がり角をうまく切り返すたび、押し切った時にヒビが入り、全部入ると割れてダメージ | 済 |
| 失敗しても罰なし | 1 つ失敗するとその盾は割れないだけ。ロングが終わると静かに消える | 済 |
| リアルなヒビ | 起点から放射状に伸びて枝分かれする、ガラスのようなヒビ。入った瞬間に起点が光る | 済 |
| 音のずれを直した | ヒビの音が少し遅れて鳴っていたのを、成功が決まった瞬間に鳴るように | 済 |
| 盾が曲がりについてくる | ロングの曲がりに合わせて盾の位置が追いかける | 済 |

### 「入力に返すのがゲーム」→ 叩くたびに手応え（#6）

| 工夫 | 中身 | 状態 |
|---|---|---|
| 攻撃の光 | 叩くと判定円から敵へ光が飛ぶ。WEAK は太い金色 | 済 |
| 着弾 | 光が届いた瞬間に輪と火花、敵が一瞬光る（届いた時に合わせて光らせる） | 済 |
| 必殺技 | ゲージ（フラスコ）が溜まると発動。チャージ中のノーツで威力が決まり、弱点のキーを狙ってビーム。弱点なら大ダメージ | 済 |
| 弱点は必殺技の時だけ | 普段のノーツは譜面で決まっていて狙えないので、弱点は必殺技の時だけにした | 済 |
| ビームを派手に | 太い金の帯 ＋ 色とりどりの細い光 24 本 ＋ 雷 3 本 | 済 |
| 判定の文字 | PERFECT / GREAT / GOOD を、戦闘らしい WEAK / HIT / GRAZE / MISS に。出るたびに少しランダムに傾く | 組み込み済み（MISS のポップと結果画面は残り） |

### 「叩いたら音楽がハマる」→ 音でも返す（#11）

| 工夫 | 中身 | 状態 |
|---|---|---|
| ボルテージで曲が開く | ボルテージが低い時は曲がくぐもっていて、上がるほど高い音が戻ってはっきり聞こえる（XAudio2 のローパスフィルター。パートごとの音源がなくてもできる） | 組み込み済み（今はノイズ版を使用、切り替え可） |
| ノイズ版 | くぐもらせる代わりに、ボルテージが低い時にノイズを重ねる。3 種類から選べる | 組み込み済み・要確認 |
| ON / OFF | セレクト画面でノイズの ON / OFF を選べる | 済 |

### 「見る → どのキーか → 叩く、の一手間」（#14）

| 工夫 | 中身 | 状態 |
|---|---|---|
| 弱点にキーの画像 | 必殺技の時、弱点にそのキー（S D F J K L）の画像を出し、残り時間の輪で囲む | 済 |
| セレクト画面の操作 | 曲の切り替え・ハイスピ・決定のキーを画像で表示。オプションは選んでいる行を枠で囲み、TAB と矢印で「次に何を押せばいいか」を出す | 済 |

## 3. 速さの改善

| 改善 | 中身 | 状態 |
|---|---|---|
| シェーダーを使い回す | 2D の画像を 1 つ作るたびに同じシェーダーをコンパイルしていた（1 回の起動で数十回）。1 回目だけコンパイルして覚え、2 回目からは使い回す | 済 |
| 画像を使い回す | 同じ画像ファイルを何度も読んでいたのを、1 回読んで共有する | 済 |
| 効果 | 起動・シーンの切り替えが速くなった。遊んでいる最中の小さな引っかかり（流れる四角を作るたびのコンパイル）もなくなった | 済（数字は測る予定） |

## 4. 直した主な不具合

| 症状 | 原因 | 状態 |
|---|---|---|
| 六角形や輪が横線につぶれる | 円の点を作る式から「上」の向きが抜けていた | 済 |
| ランクの画像が増え続ける | 毎フレーム呼ばれる所で画像を作っていた | 済 |
| 結果画面の数字が全部 0 | 関数の途中に `return` が残っていた | 済 |
| セレクトでスコアを出すとエラー | 結果の入れ物を数字として扱っていた。曲ごとの自己ベストの仕組みに作り直した | 済 |
| 敵を光らせるシェーダーのエラー | 色を受け取る型が float だった（float4 にする） | 済 |
| ボルテージの変化がわかりにくい | 上がる所が引き算になっていて、下がる処理がなかった | 修正案あり |
| ペンライトの色と振りがおかしい | 2 行が 1 行に混ざっていた | 修正案あり |
| 判定の文字の角度が使えない | 同じ名前の構造体がクラスの外と中に 2 つあった | 済 |
