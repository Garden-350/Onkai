# エディター改造その3（11/16）

| # | やりたいこと | 直した所 |
|---|---|---|
| 1 | 窓の背景に好きな絵 | **表示 → 窓の背景...** で、窓ごとに絵・濃さ・合わせ方（いっぱいに / 全体を見せる）を選ぶ。選んだ物は `editor_settings.json` に残る |
| 2 | 最小化すると止まる | `Game::Render` の途中の `return` で ImGui のフレームを閉じていなかった → `ImGui::EndFrame()` を足した |
| 3 | 譜面と曲を一覧から選ぶ | 新しい「ファイル」の窓（譜面 / 曲のタブ）。譜面はクリック → 確認 → 開く。曲はクリックで、すぐその曲になる |
| 4 | F5 で後ろの譜面が見える | テストプレイ中は、まんなかを黒い窓でふさぐ（すき間からクリックしても、ノーツが置かれない） |

## 入れ方
1. いつも通りバックアップ
2. 置き換え：`Game.cpp` `Game.h` `EditorShell.cpp` `EditorShell.h` `ChartExtras.cpp`
3. 新しいファイル：`FileBrowser.cpp` `FileBrowser.h` → フォルダに置いて、VS の「ソース ファイル」を右クリック → 追加 → 既存の項目
4. ビルド（変な所が残ったら「リビルド」）
5. 「ファイル」の窓が浮いて出たら：**表示 → 窓の並べ方を元に戻す**（「ノーツ」とタブで並ぶ）

## 変えた所
### EditorShell
- `PanelBackground()`（新）：`ImGui::Begin` の直後に呼ぶと、その窓に背景を付けられる。`BeginPanel` の窓は自動
- `AddImageFolder()`（新）：背景に選べる絵を探すフォルダ。エディターの `asset` と、ゲームの `assets` を登録（中のフォルダも探す。png / jpg / bmp）
- `TextureSize()`（新）：絵の大きさ。`Texture()` は日本語のパスも読めるようにした
- 見た目：子の窓（BeginChild）の背景を透明に（絵が見えるように）
- 表示メニューに「窓の背景...」

### Game.cpp
- `Initialize`：`AddImageFolder` を 2 行
- `Render` の最初：`return` の前に `ImGui::EndFrame()`。最小化中はテストプレイの窓も隠す
- `Render`：`FileBrowser::DrawPanel`（開く・保存・曲を変える の 3 つを渡す）
- 設定・ノーツ一覧・判定円・再生・Grid Tools・Pattern Tools の `Begin` の後に `EditorShell::PanelBackground();`
- `LoadAudioFile()`（新）：LoadChart の中にあった曲の読み込みを外に出した（LoadChart と曲タブで同じ物を使う）
- `SetupEditorCommands`：「ファイル」の窓を左に

### Game.h
- `bool LoadAudioFile(const std::string& file);` を 1 行

### ChartExtras.cpp
- `DrawGameCover`（新）：テストプレイ中、まんなかを黒い窓でふさいで一番上に。上に「テストプレイ中」、読み込み中は「ゲームを読み込み中…」

### FileBrowser.cpp / .h（新）
- 譜面：`charts/*.json`。曲：`asset/bgm/*.wav, *.mp3`。2 秒ごとにフォルダを見直す。絞り込み・新しい順

## 確かめること
- [ ] 最小化 → 戻す で止まらない
- [ ] 表示 → 窓の背景... → 窓「設定」→ 絵をクリック → 設定の窓の後ろに出る。濃さ・合わせ方が変わる。起動し直しても残る
- [ ] ファイル → 譜面 → クリック → 「保存しないで開く」で開く。名前の欄も変わる
- [ ] ファイル → 曲 → クリック → 右の音量の帯が変わる・再生でその曲。保存すると譜面に残る
- [ ] F5 → まんなかが黒くなり、ゲームの上下（左右）に譜面が見えない

## 自分の絵を背景にしたいとき
エディターの `asset` の中（例：`asset/panel_bg/`）に png / jpg を入れて、背景の窓の「探し直す」。
