# ロングノーツ「ビーム化」＋ホールド中「魔法障壁」＋「キラキラパーティクル」追加ガイド

やりたいことは3つ。
1. ロングノーツの見た目を、今の「やり（sentan/dou/oの3パーツ）」から、既にあるビーム描画（`HomingBeamSystem::DrawBeamSegmentWithColor`）を流用した「ビーム」に変える。新しくFBXを作る必要もHLSLを新規で書く必要もなし。
2. ロングノーツを保持成功中（`longStarted && !longFailed`）の間、そのレーンの判定キー位置に、レーン色でティントした一枚板（テクスチャ貼り付けだけ）の「魔法障壁」を出す。前回失敗した`BarrierQuad`（六角形グリッドのHLSL）とは別物として、新しくシンプルなクラスを作る。
3. 保持中はそのレーンの判定キー位置から、キラキラした粉のようなパーティクルを継続的に出す。これは既存の`Particle`/`ParticleQuad`をそのまま使うので新規クラスは不要。

対象ファイルは実際のプロジェクト（`ChartObject.cpp`, `ChartObject.h`, 新規3ファイル）から直接、現在の中身を確認した上で書いています。

---

## 0. 全体の作業順序

1. 新規ファイルを3つ作る：`BarrierPlate.h` / `BarrierPlate.cpp` / `shader/barrierPlatePS.hlsl`
2. テクスチャを1枚用意する：`assets/texture/barrier.png`
3. `ChartObject.h` を編集（include追加・メンバ変数追加）
4. `ChartObject.cpp` を編集
   - `Init()`：`m_BarrierPlate.Init(...)` を1行追加
   - `DrawLongNotes()`：中身を丸ごと置き換え（ビーム化）
   - `Update()`：ホールド中スパークル生成ブロックを追加
   - `Draw()`：魔法障壁の描画ブロックを追加
5. ビルドして確認

新しいHLSLファイルを作るときは、**必ず`register(b6)`を使うこと**（`Shader::UpdatePSConstantBuffer`が`PSSetConstantBuffers(6, ...)`にハードコードされているため。b0などにすると「完成した状態でいきなり出る」みたいな、値が壊れて見える系のバグになる）。あと、Visual Studioで新規`.hlsl`ファイルを作ると保存時にUTF-8 BOM付きになって`X3000: Illegal character`エラーが出ることがあるので、その場合は前回と同じように**メモ帳で開き直して「ANSI」で保存し直す**と直る。

## 1. 新規ファイル：BarrierPlate.h

`MagicCircleQuad`と全く同じ構造（板1枚・テクスチャ貼るだけ）にしてあります。プロジェクト内で既に動いている実装パターンをそのままコピーしているので、安全性が高いです。

```cpp
#pragma once
#include "VertexBuffer.h"
#include "IndexBuffer.h"
#include "Shader.h"
#include "Texture.h"
#include "Renderer.h"
#include <SimpleMath.h>

// ============================================================
// BarrierPlate : ロングノーツを保持成功中に、判定キーの位置へ表示する
//   「魔法障壁」の板1枚だけのクワッド。
//   MagicCircleQuadと同じ構造で、テクスチャをレーン色でティントして
//   貼り付けるだけのシンプルな実装（進行度による扇形の描画などはしない）。
// ============================================================
class BarrierPlate
{
private:
	struct BarrierPlateParms
	{
		float alpha;
		float padding0[3];		// 16バイトアライメント
		DirectX::SimpleMath::Vector4 tintColor;
	};	// sizeof == 32

	Shader m_Shader;
	Texture m_Texture;
	VertexBuffer<VERTEX_3D> m_VertexBuffer;
	IndexBuffer m_IndexBuffer;

public:
	void Init(const char* texturePath);

	// center    : ワールド座標（判定キーの位置）
	// scale     : 板の一辺の大きさ
	// alpha     : 板全体の不透明度(0〜1)。明滅などに使う
	// tintColor : レーン色（GetLaneColorの戻り値をそのまま渡す）
	void Draw(const DirectX::SimpleMath::Vector3& center, float scale,
		float alpha, const DirectX::SimpleMath::Vector3& tintColor);
};
```

## 2. 新規ファイル：BarrierPlate.cpp

```cpp
#include "BarrierPlate.h"

using namespace DirectX::SimpleMath;

void BarrierPlate::Init(const char* texturePath)
{
	std::vector<VERTEX_3D> verts(4);
	verts[0].position = Vector3(-0.5f, 0.5f, 0.0f);
	verts[1].position = Vector3(0.5f, 0.5f, 0.0f);
	verts[2].position = Vector3(-0.5f, -0.5f, 0.0f);
	verts[3].position = Vector3(0.5f, -0.5f, 0.0f);
	for (int i = 0; i < 4; i++)
	{
		verts[i].normal = Vector3(0.0f, 0.0f, -1.0f);
		verts[i].color = Color(1.0f, 1.0f, 1.0f, 1.0f);
	}
	verts[0].uv = Vector2(0.0f, 0.0f);
	verts[1].uv = Vector2(1.0f, 0.0f);
	verts[2].uv = Vector2(0.0f, 1.0f);
	verts[3].uv = Vector2(1.0f, 1.0f);
	m_VertexBuffer.Create(verts);

	std::vector<unsigned int> idx = { 0,1,2,3 };
	m_IndexBuffer.Create(idx);

	// ライティング不要：unlitTextureVS + 専用PS
	m_Shader.Create("shader/unlitTextureVS.hlsl", "shader/barrierPlatePS.hlsl");
	m_Shader.CreatePSConstantBuffer(sizeof(BarrierPlateParms));

	if (!m_Texture.Load(texturePath))
	{
		char buf[256];
		sprintf_s(buf, "[BarrierPlate] Texture load FAILED: %s\n", texturePath);
		OutputDebugStringA(buf);
	}
}

void BarrierPlate::Draw(const Vector3& center, float scale, float alpha, const Vector3& tintColor)
{
	Matrix world = Matrix::CreateScale(scale) * Matrix::CreateTranslation(center);
	Renderer::SetWorldMatrix(&world);

	m_Shader.SetGPU();

	BarrierPlateParms parms = {};
	parms.alpha = alpha;
	parms.tintColor = Vector4(tintColor.x, tintColor.y, tintColor.z, 1.0f);
	m_Shader.UpdatePSConstantBuffer(&parms, sizeof(parms));

	m_VertexBuffer.SetGPU();
	m_IndexBuffer.SetGPU();
	Renderer::GetDeviceContext()->IASetPrimitiveTopology(D3D11_PRIMITIVE_TOPOLOGY_TRIANGLESTRIP);

	Renderer::SetUV(0.0f, 0.0f, 1.0f, 1.0f);
	m_Texture.SetGPU();

	Renderer::GetDeviceContext()->DrawIndexed(4, 0, 0);
}
```

## 3. 新規ファイル：shader/barrierPlatePS.hlsl

`magicCireclePS.hlsl`と同じ場所（`shader`フォルダ）に作成。中身はできる限りシンプルにしてあります（前回のBarrierQuadの六角形グリッドのような複雑な計算は一切なし。テクスチャを読んで色を掛けるだけ）。

```hlsl
#include "common.hlsl"

Texture2D barrierTex : register(t0);
SamplerState samp : register(s0);

cbuffer BarrierPlateParams : register(b6)
{
    float alpha;
    float3 padding0;
    float4 tintColor;
}

float4 main(in PS_IN input) : SV_TARGET
{
    float4 tex = barrierTex.Sample(samp, input.tex);
    float3 color = tex.rgb * tintColor.rgb;
    return float4(color, tex.a * alpha);
}
```

保存する時、もし`X3000: Illegal character in shader file`が出たら、これも前回と同じくメモ帳で「ANSI」保存し直してください。

## 4. 用意してほしいテクスチャ

`assets/texture/barrier.png` という名前で1枚。

- 正方形（512×512くらいが目安。他のテクスチャに合わせて調整してOK）
- 背景は透明（PNGのアルファ）にして、盾・結界っぽい模様（六角形、魔法陣風の円、ガラスのひび割れ風など）だけ描く
- **色はできるだけ白〜薄いグレー系にしてください**。理由：シェーダー側で `テクスチャの色 × レーン色` を計算して色をつけるので、テクスチャ自体が既に濃い色だと、レーン色をかけても意図した色にならないため（真っ白に近いほど、レーン色がそのまま綺麗に出ます）

### 6-2. DrawLongNotes() を丸ごと置き換え

```cpp
void ChartObject::DrawLongNotes(Camera* cam)
{
	constexpr float kGraceTime = 0.5f;		// 判定ラインを越えても先端が進み続ける猶予秒数
	constexpr float kBodySpacing = 0.02f;	// dou（本体）を敷き詰める間隔（秒）。小さいほど密になるが重くなる
	constexpr int   kMaxBodySegments = 60;	// dou描画数の安全上限（負荷対策）

	// 各パーツごとに「専用モデルがあればそれを、無ければTAPモデルを」使う
	auto& sentanRenderer = m_LongSentanLoaded ? m_LongSentanRenderer : m_MeshRenderer;
	auto& sentanShader = m_LongSentanLoaded ? m_LongSentanShader : m_Shader;
	auto& sentanSubsets = m_LongSentanLoaded ? m_LongSentanSubsets : m_Subsets;
	auto& sentanMaterials = m_LongSentanLoaded ? m_LongSentanMaterials : m_Materials;
	auto& sentanTextures = m_LongSentanLoaded ? m_LongSentanTextures : m_Textures;

	auto& douRenderer = m_LongDouLoaded ? m_LongDouRenderer : m_MeshRenderer;
	auto& douShader = m_LongDouLoaded ? m_LongDouShader : m_Shader;
	auto& douSubsets = m_LongDouLoaded ? m_LongDouSubsets : m_Subsets;
	auto& douMaterials = m_LongDouLoaded ? m_LongDouMaterials : m_Materials;
	auto& douTextures = m_LongDouLoaded ? m_LongDouTextures : m_Textures;

	auto& oRenderer = m_LongOLoaded ? m_LongORenderer : m_MeshRenderer;
	auto& oShader = m_LongOLoaded ? m_LongOShader : m_Shader;
	auto& oSubsets = m_LongOLoaded ? m_LongOSubsets : m_Subsets;
	auto& oMaterials = m_LongOLoaded ? m_LongOMaterials : m_Materials;
	auto& oTextures = m_LongOLoaded ? m_LongOTextures : m_Textures;

	for (auto& note : m_Notes)
	{
		if (!note.IsLong()) continue;
		if (note.judged) continue;

		float displayStart = note.GetSpawnTime();	// 出現時刻
		float arrivalTime = note.arrivalTime;		// 先端が判定ラインに着く時刻
		float endTime = note.time;					// 終端が判定ラインに着く時刻（消滅予定）
		float holdDuration = endTime - arrivalTime;	// ノーツの長さ（先端と終端の時間差）

		// 出現〜到達が短すぎる（≒0秒）場合は0除算やワープ表示を避けるためスキップ
		if (arrivalTime - displayStart <= 0.0001f) continue;
		if (holdDuration <= 0.0001f) holdDuration = 0.0001f;

		// 終端が消えるまで（猶予込み）の間だけ表示対象とする
		float extendedEnd = endTime + kGraceTime;
		if (m_MusicTime < displayStart || m_MusicTime > extendedEnd) continue;

		// ── 1) sentan（先端）の現在位置 ──
		// arrivalTimeを過ぎてもkGraceTime秒だけ進み続ける（急に消えないようにするため）
		float headTime = std::min(m_MusicTime, endTime);
		Vector3 headPos = NotePath::EvaluateLongNotePosition(note, headTime);
		{
			Matrix world = Matrix::CreateScale(20.0f) * Matrix::CreateTranslation(headPos);
			ModelUtil::DrawModel(sentanRenderer, sentanShader, sentanSubsets, sentanMaterials, sentanTextures, world);
		}

		// ── 3) o（終端の輪）の現在位置 ──
		// sentanよりholdDuration秒だけ遅れて追従する（まだ出現範囲に入っていなければ非表示）
		float tailTime = headTime - holdDuration;
		bool tailVisible = (tailTime >= displayStart);
		if (tailVisible)
		{
			Vector3 tailPos = NotePath::EvaluateLongNotePosition(note, tailTime);
			Matrix world = Matrix::CreateScale(20.0f) * Matrix::CreateTranslation(tailPos);
			ModelUtil::DrawModel(oRenderer, oShader, oSubsets, oMaterials, oTextures, world);
		}

		// ── 2) dou（本体・鎖）の描画 ──
		// tailTime〜headTimeの区間を一定間隔でサンプリングし、間を鎖状に敷き詰める
		{
			float bodyStart = tailVisible ? tailTime : displayStart;
			float bodyEnd = headTime;
			float bodyDuration = bodyEnd - bodyStart;
			if (bodyDuration > 0.0001f)
			{
				int segments = std::max(2, (int)std::ceil(bodyDuration / kBodySpacing));
				segments = std::min(segments, kMaxBodySegments); // 描画数に上限をかけて負荷を抑える

				for (int s = 1; s < segments; s++) // 両端(sentan/o)は上ですでに描画済みなので中間だけ
				{
					float p = (float)s / (float)segments;
					float sampleTime = bodyStart + bodyDuration * p;
					Vector3 pos = NotePath::EvaluateLongNotePosition(note, sampleTime);
					Matrix world = Matrix::CreateScale(10.0f) * Matrix::CreateTranslation(pos);
					ModelUtil::DrawModel(douRenderer, douShader, douSubsets, douMaterials, douTextures, world);
				}
			}
		}
	}
}
```

**代わりにこれを追加：**

```cpp
// ============================================================
// DrawLongNotes : ロングノーツを、判定キーへ撃ち込まれる「ビーム」として描画する。
//   以前はsentan(先端)/dou(本体・鎖)/o(終端の輪)の3パーツのFBXモデルを
//   並べて描画していたが、視認性向上のためHomingBeamSystemの
//   DrawBeamSegmentWithColorを流用したビーム表現に変更した。
//   （sentan/dou/o用のモデルロード自体はInit()に残っているが、
//     この関数ではもう使わない。消しても動作に影響はない）
//
//   時間の流れ：
//     displayStart(出現) → arrivalTime(先端が判定ラインに到達) → endTime(終端が到達し消える)
// ============================================================
void ChartObject::DrawLongNotes(Camera* cam)
{
	constexpr float kGraceTime = 0.5f;			// 判定ラインを越えても先端が進み続ける猶予秒数
	constexpr float kCoreThicknessX = 16.0f;	// ビームの芯（明るい部分）の太さ。見た目調整用
	constexpr float kCoreThicknessY = 16.0f;
	constexpr float kGlowThicknessX = 55.0f;	// ビームのグロー（柔らかく広がる部分）の太さ。見た目調整用
	constexpr float kGlowThicknessY = 55.0f;

	Renderer::SetBlendState(BS_ADDITIVE);

	for (auto& note : m_Notes)
	{
		if (!note.IsLong()) continue;
		if (note.judged) continue;

		float displayStart = note.GetSpawnTime();	// 出現時刻
		float arrivalTime = note.arrivalTime;		// 先端が判定ラインに着く時刻
		float endTime = note.time;					// 終端が判定ラインに着く時刻（消滅予定）
		float holdDuration = endTime - arrivalTime;	// ノーツの長さ（先端と終端の時間差）

		// 出現〜到達が短すぎる（≒0秒）場合は0除算やワープ表示を避けるためスキップ
		if (arrivalTime - displayStart <= 0.0001f) continue;
		if (holdDuration <= 0.0001f) holdDuration = 0.0001f;

		// 終端が消えるまで（猶予込み）の間だけ表示対象とする
		float extendedEnd = endTime + kGraceTime;
		if (m_MusicTime < displayStart || m_MusicTime > extendedEnd) continue;

		// ── ビームの先端（head）── arrivalTimeを過ぎてもkGraceTime秒だけ進み続ける
		float headTime = std::min(m_MusicTime, endTime);
		Vector3 headPos = NotePath::EvaluateLongNotePosition(note, headTime);

		// ── ビームの後端（tail）── holdDuration秒だけheadより遅れて追従する
		float tailTime = headTime - holdDuration;
		bool tailVisible = (tailTime >= displayStart);
		float bodyStart = tailVisible ? tailTime : displayStart;
		Vector3 tailPos = NotePath::EvaluateLongNotePosition(note, bodyStart);

		// 押しっぱなしに失敗している間は、暗く・色を落として「失敗した感」を出す
		Vector3 laneColor = GetLaneColor(note.lane);
		Vector3 beamColor = note.longFailed ? Vector3(0.4f, 0.4f, 0.4f) : laneColor;
		float coreIntensity = note.longFailed ? 0.3f : 2.0f;
		float glowIntensity = note.longFailed ? 0.15f : 0.7f;

		// 芯（細く明るい）
		m_BeamSystem.DrawBeamSegmentWithColor(cam, tailPos, headPos,
			kCoreThicknessX, kCoreThicknessY, beamColor, coreIntensity);
		// グロー（太く柔らかい）
		m_BeamSystem.DrawBeamSegmentWithColor(cam, tailPos, headPos,
			kGlowThicknessX, kGlowThicknessY, beamColor, glowIntensity);
	}

	Renderer::SetBlendState(BS_NONE);
}
```

### 6-3. Update() にホールド中スパークル生成を追加

**この行：**


**の直前に、これを追加**（パーティクルの寿命更新ループのすぐ後、`m_ComboHud.Update(deltaTime);` の前）：

```cpp
	// ── ロングノーツを保持成功中のレーンに、キラキラした粉パーティクルを継続的に出す ──
	{
		constexpr float kSparkleInterval = 0.04f;	// 何秒おきに1粒出すか。小さいほど密になる（重くなる）
		bool holding[6] = { false,false,false,false,false,false };
		for (auto& note : m_Notes)
		{
			if (!note.IsLong()) continue;
			if (note.judged) continue;
			if (!note.longStarted || note.longFailed) continue;
			if (note.lane < 0 || note.lane >= 6) continue;
			holding[note.lane] = true;
		}
		for (int lane = 0; lane < 6; lane++)
		{
			if (!holding[lane])
			{
				m_BarrierSparkleTimer[lane] = 0.0f;
				continue;
			}
			m_BarrierSparkleTimer[lane] += deltaTime;
			while (m_BarrierSparkleTimer[lane] >= kSparkleInterval)
			{
				m_BarrierSparkleTimer[lane] -= kSparkleInterval;

				Vector3 pos = m_JudgeCircles[lane].GetPosition(m_MusicTime);
				Vector3 laneColor = GetLaneColor(lane);
				float deg = (float)(rand() % 360);

				Particle p(
					pos,
					0.5f,                                  // 寿命（短め）
					25.0f,                                 // 重力（軽くふわっと落ちる）
					Color(laneColor.x, laneColor.y, laneColor.z, 1.0f),
					Color(laneColor.x, laneColor.y, laneColor.z, 0.0f),
					0.4f,                                  // フェード開始位置
					16.0f,                                 // 開始サイズ（小さい粉）
					2.0f,                                  // 終了サイズ
					Vector3(35.0f, 60.0f, 35.0f),          // 初速
					deg
				);
				m_Particle.push_back(p);
			}
		}
	}

	m_ComboHud.Update(deltaTime);
```

パーティクルの描画自体は、既存の`Draw()`内にある「パーティクル（判定ヒット時の花びら演出）」のループが`m_Particle`を全部まとめて描画してくれるので、Draw側に新しく描画コードを足す必要はありません。

## 7. 見た目の調整パラメータまとめ

ビルドが通って一通り動いたら、好みに応じて数値を触ってみてください。

- ビームの太さ：`DrawLongNotes()`内の`kCoreThicknessX/Y`（芯）と`kGlowThicknessX/Y`（グロー）
- ビームの明るさ：`coreIntensity` / `glowIntensity`
- 障壁の板の大きさ：`Draw()`に追加した`kBarrierScale`
- 障壁の明滅の速さ：`sinf(m_MusicTime * 6.0f)`の`6.0f`部分
- スパークルの密度：`Update()`に追加した`kSparkleInterval`（小さいほど密）
- スパークルの見た目：`Particle`コンストラクタの寿命・サイズ・初速・重力の各引数

## 8. （任意・優先度低）不要になったモデル読み込みの整理

`DrawLongNotes()`がFBXモデルを使わなくなったので、`Init()`内の以下3ブロック（sentan/dou/oのモデルロード）はもう描画には使われません。ただし**残しておいても動作に支障はない**ので、急いで消す必要はないです。プロジェクトが落ち着いたタイミングで、容量削減のために消したくなったら教えてください（`ChartObject.h`のメンバ変数も含めて、まとめて削除手順を出します）。
