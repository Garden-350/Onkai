# コンボで盛り上がる演出 組み込みガイド

## できること

コンボがつながるほど、少しずつ盛り上がっていきます。

| コンボ | 段階 | 見た目と音 |
|---|---|---|
| 0〜9 | 0 | 曲は少しこもった音（高い音が削られている）。ペンライトはまばら・緑・暗め。スポットライトも暗め |
| 10〜 | 1 | 曲が少し開く。ペンライトが増え、色とりどりの人が出始める |
| 30〜 | 2 | 〃 |
| 60〜 | 3 | 〃 |
| 100〜 | 4（最大） | 曲が元の音に戻る（フィルターなし）。ペンライト全員が色とりどりで、拍ぴったりにそろって振る。スポットライトも今までの明るさ |

ミスしてコンボが切れても、一気には下がりません。一番上から 0 まで 16 秒かけてゆっくり下がり、その途中でまたつなげば、そこから上がり直します。

「拍に合わせた音」は、新しい音を足すのではなく、**曲そのものの高い音（シンバルやハイハットなど）がだんだん聞こえてくる**ようにしています。音を楽器ごとに分けていなくても、曲全体にフィルターをかけるだけでできます。タップ音（クラップ）ともぶつかりません。

### sound.cpp ：`Sound::SetVolumeDynamic` の下に足す

```cpp
// 曲にローパスフィルターをかける
//   cutoffHz : この周波数より高い音を削る。0 以下ならフィルターなし（元の音）
void Sound::SetLowPassDynamic(float cutoffHz)
{
	if (!m_pDynamicVoice) return;

	XAUDIO2_FILTER_PARAMETERS fp = {};
	fp.Type = LowPassFilter;
	fp.OneOverQ = 1.0f;	// 1.0 で、削り始める所が盛り上がらない素直なかかり方
	if (cutoffHz <= 0.0f)
	{
		fp.Frequency = XAUDIO2_MAX_FILTER_FREQUENCY;	// 1.0 ＝ フィルターなしと同じ
	}
	else
	{
		// XAudio2 は Hz ではなく「2 × sin(π × Hz ÷ サンプリング周波数)」で指定する
		const float sampleRate = (float)m_dynamicWfx.Format.nSamplesPerSec;
		float f = 2.0f * sinf(3.14159265f * cutoffHz / sampleRate);
		if (f > XAUDIO2_MAX_FILTER_FREQUENCY) f = XAUDIO2_MAX_FILTER_FREQUENCY;
		fp.Frequency = f;
	}
	m_pDynamicVoice->SetFilterParameters(&fp);
}
```

`<cmath>` はもう include されているので、`sinf` はそのまま使えます。

### （おまけ・任意）根本のランプが丸く出ていないかも

見ていて気づいたのですが、`SpotlightParams` の `mode` が `int` になっていて、シェーダー側（spotlightPS.hlsl）は `float mode` です。`p.mode = 1;` の int の 1 をシェーダーが float として読むと 0.0000…01 くらいの数になり、`mode < 0.5` で「光の柱」として描かれています。つまり根本のランプが、丸い光ではなく小さな柱になっているはずです。

直すなら次の 2 か所です（見た目が変わるので、今の見た目が気に入っていればそのままで大丈夫です）。

```cpp
// SpotlightRow.h
int mode;      →  float mode;
// SpotlightRow.cpp（199行目あたり）
p.mode = 1;    →  p.mode = 1.0f;
```

### ChartObject.h ：private の `m_LongShield` の下に足す

```cpp
	float m_LastLowPass = -100.0f;	// 最後に送ったフィルターの値（同じ値を毎フレーム送らないため）
	static constexpr float kLowPassMinHz = 2500.0f;		// 盛り上がり 0 の時、これより高い音を削る（小さいほどこもる）
	static constexpr float kLowPassOpenHz = 7000.0f;	// 最大の少し手前でここまで開く（最大でフィルターなし）
```

```cpp

	m_LastLowPass = -100.0f;
```

### ChartObject.cpp ：Update の `m_ComboHud.Update(deltaTime);` の下に足す

```cpp
	// ---- 盛り上がり：コンボで上がり、ミスでゆっくり下がる ----
	m_Hype.Update(deltaTime, m_JudgeSystem.GetComboCount());
	{
		// 盛り上がるほど、曲の高い音が聞こえてくる（最大でフィルターなし）
		float h = m_Hype.Get01();
		float hz = 0.0f;	// 0 = フィルターなし
		if (h < 0.999f) hz = kLowPassMinHz * std::pow(kLowPassOpenHz / kLowPassMinHz, h);
		if (std::fabs(hz - m_LastLowPass) > 1.0f)
		{
			sound.SetLowPassDynamic(hz);
			m_LastLowPass = hz;
		}
	}
```

`std::pow` を使っているのは、耳は Hz を「足し算」ではなく「かけ算」で感じるからです。2500 → 7000 を `pow` でつなぐと、2500 → 3200 → 4200 → 5400 → 7000 のように、どの段階でも同じくらい「開いた」と感じます（ふつうの足し算だと、最初の方だけ変化が大きく聞こえます）。

## しくみ

### HypeMeter：コンボ → 盛り上がり度

コンボ数から「今いるべき段階」（0〜4）を決めて、なめらかに動く `m_Level` をそこへ近づけます。上がる時は 1 秒に 2 段階（すぐ反応する）、下がる時は 1 秒に 0.25 段階（ゆっくり）です。ミスでコンボが 0 になると目標は 0 になりますが、`m_Level` は少しずつしか下がらないので、「ゆっくり下がる」になります。

### ペンライトの振り

`cos(π × 拍の位置)` は、拍ちょうどで +1 と -1 を交互にとります。これを振りの角度にすると、1 拍ごとに右・左・右・左と振ります。`pow(|cos|, 0.6)` で端の方を少し平らにして、端でためる振り方にしています。

一人ひとりに少しだけ「振りのずれ」（`swingJitter`、±0.3 拍）を持たせて、`ずれ × (1 − 盛り上がり)` だけ遅らせています。盛り上がり 0 では人によってばらばら、最大では全員が拍ぴったりにそろいます。

### ペンライトが増えていく・色が変わっていく

一人ひとりに 0〜1 のランダムな「出てくる順番」（`order`）と「色が変わる順番」（`colorPick`）を持たせています。盛り上がりがその数を超えた人から、振り始めたり色とりどりの色になったりします。毎フレームランダムに選ぶのではなく、最初に決めた順番を使うので、出たり消えたりしてちらつくことはありません。

### 曲のフィルター

XAudio2 のボイスには、もともとフィルターが付いています（作る時に `XAUDIO2_VOICE_USEFILTER` を付けた時だけ使えます）。ローパスフィルターは「指定した周波数より高い音を削る」もので、かけると壁の向こうで鳴っているような、こもった音になります。盛り上がるほど削る周波数を上げていき、最大でフィルターを外します。
