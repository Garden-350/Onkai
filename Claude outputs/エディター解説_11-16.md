## 1. 画面の見方

```
┌ ①メニュー ──────────────────────────────────────────────┐
├ ②ツールバー（アイコン）                                     ┤
├──────────┬──────────────────────────┬─────────────┤
│ ③設定        │ ④譜面（2D）                  │ ⑤Grid Tools / ノーツ一覧 │
│ （長い欄）    │                              ├─────────────┤
│              │                              │ ⑤Pattern Tools │
├──────────┴──────────────────────────┴─────────────┤
└ ⑥再生（下のバー）                                           ┘
```

窓はどれも、**タブ（窓の名前の所）をドラッグ**すると動かせる。ほかの窓の上に持っていくと青い印が出て、上下左右にくっつけたり、タブにまとめたりできる。並べ方は次に起動しても残る。崩れたら **表示 → 窓の並べ方を元に戻す**。

|---|---|---|
| ファイル | 保存 / 読み込み | Ctrl+S / Ctrl+O |
| 再生 | 再生・一時停止 / テストプレイ（ここから）/ テストプレイ（最初から） | ― / F5 / Shift+F5 |
| 画面 | 2D の譜面 / 3D ビュー | F2 / F3 |
| ツール | 置く / 範囲を選ぶ（コピー用） | B / M |
| ノーツ | タップ / ロング / フリック右 / フリック左 / トレース | 1 / 2 / 3 / 4 / 5 |
| 表示 | 窓を出す・消す / 窓の並べ方を元に戻す | |

|---|---|
| 💾 保存 | 譜面を保存（「Save to game too」がオンなら、ゲームの charts にもコピー） |
| 📂 開く | 「設定」のファイル名の譜面を読み込む |
| ▶ 再生 | エディターの中で再生・一時停止（再生中は青くなる） |
| 枠付き ▶ | **テストプレイ（ここから）**：保存 → 本物のゲームを、今見ている小節の少し前から起動 |
| 枠付き ｜▶ | **テストプレイ（最初から）** |
| ▥ 2D / ⬡ 3D | まんなかを 2D の譜面 / 3D の見た目に切り替え（選んでいる方が青） |
| ✎ 置く | 普通の状態。譜面をクリックするとノーツが置ける |
| ⬚ 範囲 | 譜面をドラッグして範囲を選ぶ（コピー・貼り付け用。右クリックでやめる） |

ボタンにマウスを乗せると、名前とショートカットが出る。

### ③ 設定（今までの左の欄）

上から順に：

| 項目 | すること |
|---|---|
| HighSpeed | 2D の譜面の縦の間隔（大きいほど縦に広がって、細かく置きやすい） |
| Note Scale | 3D ビューのノーツの大きさ |
| Playback Speed | エディターの中で再生するときの速さ（0.25〜1 倍） |
| Approach Beats / Min Travel Time | ノーツが出てから届くまでの長さ（エディターの 3D 用。**ゲームは自分で計算し直すので、譜面の遊び心地には関係ない**） |
| Place | 置き方の説明（今日から「クリック＝届く時刻」） |
| Key / To / Hold Duration | （3D で置く時の）レーン・フリックの行き先・ロングの長さ |
| ファイル名（Fire の下の欄） | 保存・読み込みする譜面の名前（charts/<名前>.json） |
| Audio File | 曲のファイル名（asset/bgm/ の中）。入れたら一度 保存 → 読み込み |
| BPM / Auto-detect BPM / x2 / /2 | テンポ。自動で調べることもできる |
| Save to game too / Save / Load | 保存したらゲームにもコピーするか / 保存 / 読み込み |
| **Test Play** | **Play from here**：今見ている小節の「bars before」小節前から本物のゲームで遊ぶ ／ **Play from top**：最初から ／ **Auto**：オート ／ **Release exe**：Release 版のゲームを使う ／ **Show inside editor**：ゲームの窓をエディターのまんなかに入れる（今日追加）／ **Close game**：ゲームを閉じる |
| **Camera** | **+ Add at bar N**：今見ている小節にカメラの区切りを足す。1 行ごとに **bar**（何小節目に着くか）・**名前**（far / high / low … / custom）・**blend**（何拍かけて動くか）・**Try**（その少し前から本物のゲームで確かめる）・**x**（消す）。custom にすると eye（カメラの位置）と target（見る先）を数字で決められる |
| Judgge Circles | レーンごとの判定円の動き（キーフレーム） |
| Homing Beams | ホーミングビームの時刻 |
| Selected Note | 選んだノーツの細かい値と、3D の道すじの小さな図 |

### ④ 譜面（2D）

- **縦が時間**（上が未来、下が過去）。**赤い線が今の位置**（ここに届く時刻＝判定の時刻）
- **横が 6 レーン**（下に S D F J K L）。右の色の帯は曲の音量（大きい所ほど赤い）
- 横線は拍・小節（左の数字は小節番号）。紫の帯と「CAM 名前」はカメラの区切り

| 操作 | どうなる |
|---|---|
| ホイール / ↑↓ キー | 上下にスクロール（止まっている時） |
| 空いている所を**左クリック** | **今選んでいる種類のノーツを、その時刻に「届く」ように置く**（グリッドに吸着。今日変更） |
| ノーツを左クリック | 選ぶ（黄色い枠と時刻が出る） |
| ノーツをドラッグ | 時刻とレーンを動かす（ロングは曲がり点も一緒に） |
| ロングの終わり（細い横棒）をドラッグ | 長さを変える |
| 右クリック | 選んでいるノーツを消す |
| Shift + 右クリック | 選んでいるロングに曲がり点を足す（Shift を押している間、置ける所が出る） |
| Ctrl + 右クリック | 一番近い曲がり点を消す |

マウスの下の白い枠は、クリックしたら置かれる場所（グリッドに吸着した後）。

### ⑤ 右の窓

| 窓 | 中身 |
|---|---|
| ノーツ一覧 | 置いたノーツの一覧。クリックで選ぶ |
| Grid Tools | Offset（最初の拍の秒）/ Grid（1/4〜1/64）/ **Check Grid**（グリッドからずれたノーツを数える）/ **Snap All Notes**（全部グリッドに合わせる）/ Undo Snap |
| Pattern Tools | Cursor（今の位置）/ Long beats（ロングの長さ）/ **Pattern**：トリル・階段などを Lane A・Lane B・Step・Length で作って、マウスで置く（ghost）か、カーソルに置く（STAMP）/ **Copy / Paste**：範囲を選んで（マウスで箱 or 拍で指定）コピー → マウスで貼る / カーソルに貼る / ミラーで貼る / 1 回戻す |
| ノーツ（左上） | ノーツの種類を絵で選ぶ。表示を「大きい絵 / 絵＋名前 / 文字」から選べる |

### ⑥ 再生（下のバー）

| 項目 | すること |
|---|---|
| Play/Pause | エディターの中で再生・一時停止 |
| BACK | 頭に戻す（再生で消えたノーツも元に戻す） |
| スライダー / Time ± | 今の位置 |
| OK / MISS | エディターの中で叩いた結果 |

### 今日の追加分（このあと入れる物）

| 何を | どこ |
|---|---|
| **1 クリックで「届く時刻」に置く** | Game.cpp：左の欄の「Place」の 2 クリック配置ボタンをやめて説明に。譜面のクリックは、いつでも「その時刻に判定ラインへ届く」ノーツを置く（出現は Approach Beats から自動）。Pattern Tools の「Quick place」は、もう関係なし |
