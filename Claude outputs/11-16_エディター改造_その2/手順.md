# その2：入れる手順

1. **バックアップ**（エディターのフォルダを丸ごとコピー）
2. **Game.cpp**：このフォルダの Game.cpp の中身で、まるごと置き換え（Game.h は変更なし）
3. **EditorShell.h / .cpp、NotePalette.h / .cpp**：このフォルダの物で、まるごと置き換え
4. **ChartExtras.h / .cpp**：このフォルダの物で、まるごと置き換え
   （中身は今のと同じ＋PlayFromHere / PlayFromTop ＋ ゲームの窓をエディターに入れる処理。コメントは前のまま UTF-8）
5. **絵**：エディターの `asset/notes2d/` に tap.png と trace.png を入れておいた（このフォルダの asset/notes2d と同じ）
6. ビルド（ImGui はもう入れ替え済み）

## 確かめること

- 譜面の空いている所をクリック → クリックした高さ（時刻）にノーツの絵が置かれる。斜めの線や出現の点は出ない
- ノーツをクリックで選ぶ（黄色い枠と時刻）→ ドラッグで動く → 右クリックで消える
- ロングは胴の帯と終わりの横棒。横棒をドラッグで長さが変わる
- テストプレイ（F5）→ ゲームの窓がエディターのまんなかに入る。窓をクリックしてから遊ぶ。「Show inside editor」をオフにすると別の窓に戻る
- 窓の大きさや並びを変えても、ゲームの窓がまんなかについてくる

## うまくいかないとき

- ノーツが色の四角のまま：asset/notes2d/ に tap.png / trace.png が無い
- ゲームの窓が入らない：Show inside editor がオフ、またはゲームの起動に時間がかかっている（少し待つ）
- ゲームの窓でキーが効かない：ゲームの窓を一度クリックする
- ゲームの窓の中の絵がずれる・小さい：Windows の表示の拡大（125% など）の影響。100% で試してみて、教えてください
