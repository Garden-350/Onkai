# コンボ演出：こもらせる代わりにノイズをかける

## しくみ

曲そのものは加工しません。曲とは別に「ノイズだけの音」をループで鳴らし、その音量を盛り上がりで変えます。

- 盛り上がり 0（曲の始め・ミスの後）：ノイズがいちばん大きい
- コンボがつながるほど：ノイズが小さくなっていく
- 盛り上がり最大：ノイズが消えて、きれいな曲だけになる

音量を変えるだけなので、XAudio2 の `SetVolume` で済みます。ミスで盛り上がりがゆっくり下がると、ノイズもゆっくり戻ってきます。

---

## 0. ノイズの音を選ぶ

`ノイズ/` に 3 種類入れました。どれも 4 秒で、つなぎ目なしにループします。

| ファイル | 聞こえ方 |
|---|---|
| noise_hiss_サー.wav | 「サー」というテープのような音。いちばん控えめ |
| noise_vinyl_パチパチ.wav | 古いレコードの「パチパチ」。小さなサーにプチプチが混ざる |
| noise_radio_ザザッ.wav | 電波の悪いラジオの「ザザッ」。大きくなったり小さくなったりする |

気に入ったものを `assets/se/noise.wav` という名前でコピーしてください。後で入れ替えたくなったら、ファイルを上書きするだけで変わります。

## 1. sound.h ：ノイズの音を登録する

**enum と m_param の並び順は必ずそろえてください。** ずれると、ほかの効果音が全部 1 つずつずれて鳴ります。

enum の `SOUND_MIRROR_BREAK_BIG,` の下に足します。

```cpp
	SOUND_MIRROR_BREAK_BIG,
	SOUND_NOISE,			// ← 足す：盛り上がっていない時のノイズ（ループ）
```

m_param の `{"assets/se/Break.wav",false},` の下に足します（同じ位置）。

```cpp
		{"assets/se/Break.wav",false},
		{"assets/se/noise.wav",true},	// ← 足す：ループするので true
```

## 2. ChartObject.h

private の `m_LastLowPass` の近くに足します。

```cpp
	bool  m_NoisePlaying = false;					// ノイズを鳴らしているか
	static constexpr float kNoiseVolume = 0.35f;	// 盛り上がり 0 の時のノイズの大きさ（1 で元の音量）
	static constexpr bool  kUseLowPass = false;		// true にすると、前の「こもらせる」も一緒にかかる
```

## 3. ChartObject.cpp

### LoadChart の `m_Hype.Reset();` の下

```cpp
	m_NoisePlaying = false;
```

### Update の、前に足した「盛り上がり」のブロックを置き換える

```cpp
	// ---- 盛り上がり：コンボで上がり、ミスでゆっくり下がる ----
	m_Hype.Update(deltaTime, m_JudgeSystem.GetComboCount());
	const float h = m_Hype.Get01();

	// こもらせる（kUseLowPass が false の時は、いつもフィルターなし）
	{
		float hz = 0.0f;	// 0 = フィルターなし
		if (kUseLowPass && h < 0.999f) hz = kLowPassMinHz * std::pow(kLowPassOpenHz / kLowPassMinHz, h);
		if (std::fabs(hz - m_LastLowPass) > 1.0f)
		{
			sound.SetLowPassDynamic(hz);
			m_LastLowPass = hz;
		}
	}

	// ノイズ：曲が鳴っている間だけ。盛り上がるほど小さく、最大で消える
	{
		bool musicOn = m_AudioStarted && !m_AudioFile.empty() && !IsAudioFinish();
		if (musicOn && !m_NoisePlaying)
		{
			sound.Play(SOUND_NOISE);		// 曲が始まった時・ポーズが明けた時
			m_NoisePlaying = true;
		}
		else if (!musicOn && m_NoisePlaying)
		{
			sound.Stop(SOUND_NOISE);		// 曲が終わった時
			m_NoisePlaying = false;
		}

		float quiet = 1.0f - h;				// 盛り上がっていない度合い 1 → 0
		sound.SetVolume(SOUND_NOISE, kNoiseVolume * quiet * quiet);
	}
```

`quiet * quiet`（2 乗）にしているのは、少しコンボがつながっただけで、ノイズがはっきり減ったと感じられるようにするためです。

| 盛り上がり h | quiet | 音量（kNoiseVolume に対して） |
|---|---|---|
| 0 | 1 | 100% |
| 0.25（コンボ 10） | 0.75 | 56% |
| 0.5（コンボ 30） | 0.5 | 25% |
| 0.75（コンボ 60） | 0.25 | 6% |
| 1（コンボ 100） | 0 | 0%（消える） |

### StopLongSounds に足す（ポーズ中にノイズが鳴り続けないように）

```cpp
void ChartObject::StopLongSounds()
{
	sound.Stop(SOUND_CHARGE);
	sound.Stop(SOUND_NOISE);	// ← 足す
	m_NoisePlaying = false;		// ← 足す：ポーズが明けたら Update でまた鳴らす
}
```

`StopLongSounds` は終了時（Uninit）にも呼ばれるので、曲をやめた時も止まります。

## 調整する所

| 変えたいこと | 場所 |
|---|---|
| ノイズの大きさ | ChartObject.h の `kNoiseVolume`（0.35 から。うるさければ 0.2 くらい） |
| ノイズの種類 | `assets/se/noise.wav` を、ほかの wav で上書き |
| こもらせるのも一緒にやる | `kUseLowPass` を true（ラジオのノイズと一緒にすると、本当にラジオから聞こえる感じになる） |
| ノイズが消えるまでの早さ | `quiet * quiet` を `quiet`（ゆっくり）や `quiet * quiet * quiet`（早く）に |
