
自作音楽ゲーム  「音廻」　ReadMe!

 概要

奥から流れてくるノーツを、S D F J K L の6つのキーで叩くリズムゲームです。

テーマ

プレイしてる側も見てる側も楽しめる音楽ゲーム


 動作環境

  OS        : Windows 10 / 11（64bit）
  描画      : DirectX 11
  開発環境  : Visual Studio 2022（プラットフォーム x64）
  入力      : キーボード


起動方法

  1. Sounder.sln を Visual Studio で開く
  2. 構成を「x64」にしてビルドし、実行する

  画像・音・譜面は assets / charts フォルダから相対パスで読み込みます。
  exe を直接起動する場合は、「chart」「assets」「shader」フォルダを同じ階層にあることをご確認ください


操作方法

【タイトル画面】
  Enter            ゲームスタート（湖へ飛び込む演出のあと、曲選択へ）

【曲選択画面】
  S / ← / ↑        前の曲
  F / → / ↓        次の曲
  J / L            ハイスピード（ノーツの速さ）を 0.1 ずつ下げる / 上げる
  Tab              オートプレイの ON / OFF
  Enter            曲を決定してプレイ開始

  曲を選んで少し待つと、その曲のサビ付近が試聴として流れます。

【プレイ画面】
  S D F            左手の3レーン
  J K L            右手の3レーン
  Space            必殺技の発動（必殺ゲージが満タンの時だけ）
  Tab              ポーズ / 再開
  R（ポーズ中）    最初からやり直す

【リザルト画面】
  Enter            曲選択へ戻る
  R                同じ曲をもう一度プレイ

【どの画面でも】
  F11              フルスクリーン切り替え
  Esc              ゲームを終了する（確認なしで閉じるので注意）


遊び方

【ノーツの種類】
  タップ    判定円に重なった瞬間に、そのレーンのキーを押す。
  ロング    押し始めて、終わりまで押し続ける。
            途中で曲がる（別のレーンへ移る）ロングもある。
            曲がる所では、移った先のレーンのキーに押し替える。
  フリック  キャラクターを左右に動かして取るノーツ。
            左手（S D F）を押すとキャラクターが左へ、右手（J K L）を押すと右へ動く。
            ノーツが届いた時に正しい側にいれば成功。
            先に移動しておけば、届いた瞬間に判定される。

【判定】
  PERFECT / GREAT / GOOD / MISS の4段階。
  タップの判定幅は、PERFECT が前後 0.06秒、GREAT が 0.08秒、GOOD が 0.10秒です。

【必殺技（チャージ攻撃）】
  1. ノーツを叩くと、画面左のフラスコに青緑の液体が溜まる。
  2. 満タンになると液体が金色に変わり、フラスコの下に「GO!」が出る。
  3. Space で発動。次の拍から背景が金色に変わり、チャージ時間に入る。
  4. チャージ時間中に流れてくるノーツは「チャージノーツ」になる。
     うまく叩くほどフラスコに金の液体が溜まり直し、威力が上がる。
  5. チャージ時間が終わると、溜めた分の力で敵へ攻撃する。


アピールポイント

1. 視認性の改善
   ノーツは、判定円と同じ高さの平面を奥から手前へ流れてきます。
   それをカメラが見下ろす「ハイウェイ型」に変更。
   奥行きがそのまま「判定までの時間」になるので、3Dであることがプレイに直結します。
   判定時刻ちょうどに閉じるリングや、叩いた時に伸びる光の柱で、タイミングが目で分かります。
   派手な演出はレーンの外（背景・スポットライト・観客側）にだけ置き、
   ノーツの読み取りを邪魔しないようにしました。

2. プレイヤーがこうしたいになるべく返せるようにする
   ・叩いた判定に応じて、光の柱・判定文字・画面のフラッシュが反応する。
   ・ロングノーツは、押している間、障壁で受け止めるように見える。
   ・敵の六角形HPゲージが、格闘ゲームのように白い残像を残して削れる。
   ・ロングノーツをただ押すだけでなくほかのレーンにまで行くことでプレイ中のつまらないを少なくする。
   ・必殺技が溜まっていればプレイヤーが任意のタイミングで発動できるように

3. ストレスなく遊べるルール
   ・必殺技のチャージノーツは、取り逃してもミスにも、コンボ切れにもならない。
   ・フリックは「届いた時に正しい側にいるか」で判定するので、早めに動いておけば取れる。

4. 自作の譜面エディター（別プロジェクト）
   譜面は JSON 形式で、ImGui で作った専用エディターで制作しています。
   エディターでは次のことができます。
     ・BPM と offset に合わせたグリッドへの配置
     ・トリル・階段・同時押しなどのパターンの一括配置
     ・範囲コピーと貼り付け（左右反転もできる）
     ・半透明のゴーストで、置く前に配置を確認する
   収録曲「w001」（225ノーツ・約74秒）は、このエディターで作りました。
