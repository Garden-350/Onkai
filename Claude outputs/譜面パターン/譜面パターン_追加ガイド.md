# 譜面づくりを速くする：パターン・範囲コピー・1クリック配置（エディター用）

## 0. なぜ遅いのか

今のノーツ配置は、1個につき次の操作が必要。

1. 「Place Note」を押す
2. レーンのボタンを押す
3. 出現位置をクリック
4. 到達位置をクリック

ゲームはハイウェイ表示で出現位置を作り直すので、出現位置のクリックはゲーム側では使われていない。
今回の道具で、次の3つができるようにする。

- **1クリック配置**：2D の譜面画面の空いている所をクリックすると、その場所（レーン・グリッドに合った時刻）にすぐ置ける。
- **パターン**：トリル・階段・連打などを、判定ラインの位置から一気に置ける。
- **範囲コピー**：何拍分かをコピーして、別の場所に貼れる（左右反転もできる）。サビの繰り返しなどで一番効く。

---

## 1. ファイルを追加（エディターのプロジェクト）

`1_新規ファイル/PatternTool.h`、`PatternTool.cpp` をエディターのプロジェクトに追加する。

- `PatternTool.h` の先頭で `#include "Game.h"` している。`Note` 構造体が別のヘッダにあるなら、そのヘッダに変える。
- `PatternTool.cpp` の1行目は `#include "pch.h"`（エディターはプリコンパイル済みヘッダを使っているため）。

## 5. おすすめの作り方（30秒の曲なら1日で終わる流れ）

1. **土台**：Grid Tools で Offset と BPM を合わせる。グリッドを 1/8 にする。
2. **骨組み（パターン）**：曲の区切り（4小節＝16拍）ごとに判定ラインを置き、STAMP で土台を置く。
   - 例：Aメロは「Hands L/R」1/8 で 16拍、サビは「Trill」1/16 で 4拍＋「Chord」1/4 で 4拍。
   - Advance cursor を ON にしておくと、STAMP するたびに判定ラインが置いた分だけ先へ進む。続けて押していける。
3. **繰り返しはコピー**：同じメロディが2回来る所は、1回目を作ってから Copy → 2回目の頭で PASTE。Paste mirrored を ON にすると左右が入れ替わって飽きにくい。
4. **見せ場だけ手で**：曲がるロングやフリックなど、メロディに合わせたい所だけ1クリック配置で置く。
5. **最後に Check Grid**：グリッドから外れたノーツがないか確認する。

失敗したら「Undo last STAMP / PASTE」で1回分戻せる。保存前には必ず Save。
