# テストプレイでゲームが出てこない件（11/16）

## 何が起きていたか
F5 を押すと Sounder.exe は起動していた。でも「エディターの中に入れる」処理（Show inside editor、最初からオン）で、次の 3 つが重なって映らなくなっていた。

1. **ゲームを子どもの窓にしていた（SetParent）**：エディターは FLIP 方式で画面全体を描いているので、その下にある子どもの窓は上から塗りつぶされて見えない。
2. **最初の 1 枚を描く前に窓の大きさを変えると、ゲームが何も描けなくなる**：ゲームの WM_SIZE → `Renderer::ResizeWindow` でバックバッファは窓の大きさになるのに、深度バッファは 1280x720 のまま。`PostFlashEffect::EndSceneAndApply` は「バックバッファ＋深度」をセットするが、大きさが違うので DirectX がそのセットを無視する → 窓に何も描かれない（黒か、透明）。
   ※遊んでいる途中（F11 など）は、バックバッファがつながったままなので ResizeBuffers が失敗して、1280x720 の絵が引き伸ばされて「たまたま」映っていた。エディターは読み込み直後（まだ 1 枚も描いていない時）に大きさを変えるので、失敗せずに大きさが変わってしまい、映らなくなる。
3. **読み込み中に窓を触っていた**：ゲームは窓を出してから Stage1Scene を読み込む。その間に別のプロセスから SetParent すると、読み込みが終わるまでエディターまで止まる。

## 直し方
### エディター（Direct3D Win32 Game1）
- `ChartExtras.cpp` を丸ごと置き換え。
  - 子どもの窓にするのをやめた。**枠を消した普通の窓のまま、まんなかの場所にぴったり重ねる**（毎フレーム場所を合わせる。エディターを動かしても付いてくる）
  - ゲームの読み込みが終わってから重ねる。窓を動かすのは ASYNC（エディターは待たない）
  - 重ねたらゲームを前に出す → そのままキーで遊べる
  - エディターを触ってもゲームは上に残る（キーはエディターに行く）。エディターを最小化したら、ゲームも隠れる

### ゲーム（3Dゲーム作成1）
- `Renderer.h`：`m_BackBufferViewport` と `SetBackBufferTarget()` を足した
- `Renderer.cpp`：
  - `ResizeWindow`：先に描画先を外す（外さないと ResizeBuffers が失敗する）・大きさ 0 は何もしない・16:9 のビューポートを覚える
  - `SetBackBufferTarget`（新規）：バックバッファだけをセット（深度なし）→ 黒で塗る → 16:9 のビューポート
  - `Init`：2 回目の `D3D11CreateDeviceAndSwapChain` を消した（コピペの残り。1 回目のデバイスが解放されずに残っていた）
- `PostFlashEffect.cpp` 108 行目：`Renderer::SetRenderTarget(GetBackBufferRTV(), GetDepthStencilView())` → `Renderer::SetBackBufferTarget()`

## 手順
1. エディター：`ChartExtras.cpp` を置き換え（前の物は ChartExtras.cpp.bak などに取っておく）
2. ゲーム：`ゲーム側/` の 3 ファイルを見比べて貼る（git があるので、まずい時は戻せる）
3. **ゲームを Debug でビルド**（エディターのテストプレイは x64/Debug/Sounder.exe を使う）
4. エディターをビルドして F5

## 確かめること
- [ ] F5 → ゲームの窓が一瞬いつもの場所に出て、読み込みが終わるとまんなかに入る
- [ ] そのままキーで遊べる（効かなければゲームを 1 回クリック）
- [ ] 左の欄を触ってもゲームが消えない
- [ ] エディターを動かす・大きさを変えると、ゲームも付いてくる
- [ ] 「Show inside editor」をオフ → 普通の窓に戻る
- [ ] ゲームを単体で起動して F11 → 今まで通り全画面で映る（黒帯つきの 16:9 になる）

## まだ出てこない時
「Show inside editor」をオフにして F5。
- それで出る → 重ねる処理の問題。どうなったかスクショを送ってください
- それでも出ない → 譜面かゲームの方の問題。VS でゲームの「デバッグ → コマンド引数」に `--chart 1minute_move --start 10` を入れて F5 すると、止まった行が分かります
