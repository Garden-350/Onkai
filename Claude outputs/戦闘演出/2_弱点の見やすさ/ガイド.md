# 弱点部位を見やすくする（並び・判定円の印・チカチカを拍に合わせる）

## 0. 何が変わるか

| 困っていたこと | 原因 | 直し方 |
| --- | --- | --- |
| 6つの部位が一直線に見える | 敵の前に横一列＋少し山なりに並べていた。カメラが上から見下ろしているので、上下の差がつぶれて一直線に見えていた | 敵のまわりに「冠」のような弧で並べる。並べる面をカメラの方に向けるので、どの角度から見ても弧の形が保たれる |
| 弱点がどこか分かりにくい | プレイヤーは判定円を見ているのに、弱点の印は遠くの敵の上にしかなかった | 弱点のレーンの判定円を、金色の六角形と残り時間の輪で囲む。必殺技の狙いの枠も、判定円の方にも出す |
| チカチカする | 残りわずかの点滅（1秒に約5回）、狙いの枠の揺れ、叩くたびの着弾の光が、全部ばらばらのリズムで光っていた | 光り方を曲の拍に合わせた（弱点は拍ごとに膨らむ、残りわずかは半拍ごとに脈打つ）。弱点でない所への光と着弾は細く暗く、弱点への光は太く明るくして差をつけた。同じレーンの光は 0.12 秒に1つまで |

見た目の派手さはそのままで、「どこが大事か」に強弱をつけ、光るリズムを曲にそろえる方針にしている。

## 1. ファイルを置き換え

`1_新規ファイル` の6つで、プロジェクトの同じ名前のファイルを置き換える。

- `WeakPoint.h` / `WeakPoint.cpp`（並び方・判定円の印・拍に合わせた光り方）
- `AttackOrbs.h` / `AttackOrbs.cpp`（普段の光を細く暗く、弱点への光を太く明るく）
- `ImpactFx.h` / `ImpactFx.cpp`（弱点でない所の着弾を小さく暗く）

RibbonShapes.h、SpecialBeam は変えていない。

## 2. ChartObject.h

メンバーに足す（`int m_LastPressedLane = 2;` の下）。

```cpp
	float m_LastOrbTime[6] = { -100.0f, -100.0f, -100.0f, -100.0f, -100.0f, -100.0f };	// レーンごとに最後に光を飛ばした時刻
	static constexpr float kOrbMinInterval = 0.12f;	// 同じレーンから光を飛ばす最短の間隔（弱点への光は制限しない）
```

## 3. ChartObject.cpp

### 3-1. LoadChart：`m_LastPressedLane = 2;` の下に足す

	for (auto& t : m_LastOrbTime) t = -100.0f;

### 3-2. Update：`if (m_EnemyRef) m_WeakPoint.Update(...)` の上に足す

```cpp
	// 判定円の位置を渡す（弱点のレーンの判定円に印を出すため）
	for (int i = 0; i < 6 && i < (int)m_JudgeCircles.size(); i++)
		m_WeakPoint.SetLaneAnchor(i, m_JudgeCircles[i].GetPosition(m_MusicTime));
```

### 3-3. OnJudge：光を飛ばしている2行を置き換え

```cpp
	//判定円から、そのレーンの部位へ光を飛ばす（同じレーンは kOrbMinInterval に1つまで。弱点への光は毎回）
	if (m_EnemyRef && (weakHit || m_MusicTime - m_LastOrbTime[laneIndex] >= kOrbMinInterval))
	{
		m_AttackOrbs.Launch(laneIndex, pos, m_WeakPoint.GetPoint(laneIndex), GetLaneColor(laneIndex), weakHit);
		m_LastOrbTime[laneIndex] = m_MusicTime;
	}
```

## 4. 調整する所

| 変えたいこと | 場所（WeakPoint.h） |
| --- | --- |
| 冠の大きさ（敵からの距離） | `kHaloRadius`（190） |
| 冠の広がり（90 で真横まで、大きいほど下へ回り込む） | `kHaloSpanDeg`（105） |
| 冠を上下にずらす | `kHaloLift`（30） |
| 敵の体に埋もれる時 | `kHaloFront`（120）を大きく |
| 判定円の六角形の大きさ・濃さ | `kLaneMarkerRadius`（72）、`kLaneMarkerAlpha`（0.85） |
| 判定円の印を出さない | `kShowLaneMarker` を false |
| 拍ごとの膨らみの強さ | `kBeatKick`（0.18。0 で膨らまない） |
| 赤くなり始める残りの割合 | `kWarnRatio`（0.25） |
| 弱点でない部位の印 | `kMarkAlpha`（0.22。0 で消える） |

| 変えたいこと | 場所 |
| --- | --- |
| 普段の光の太さ・明るさ | AttackOrbs.h の `kWidth`、`kIntensity` |
| 弱点への光の太さ・明るさ | AttackOrbs.h の `kCritWidthMul`、`kCritIntensity` |
| 弱点でない所の着弾の明るさ | ImpactFx.h の `kSmallHitBright`（0.5） |
| 光の数をもっと減らす・増やす | ChartObject.h の `kOrbMinInterval`（大きいほど減る） |

## 5. 確認すること

1. 6つの印が、敵のまわりに弧（冠）の形で並んでいるか。左から S D F J K L の順か。
2. 弱点のレーンの判定円が、金色っぽい六角形で囲まれているか。4小節ごとに別のレーンへ移るか。
3. 弱点の六角形が、曲の拍に合わせて膨らむか。残りわずかで輪が赤くなり、半拍ごとに脈打つか。
4. 必殺技のチャージ中、狙いの枠が敵の部位と判定円の両方に出るか。
