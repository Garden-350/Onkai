 1. このプロジェクトについて
==============================================================================

  奥から流れてくるノーツを、S D F J K L の 6 つのキーで叩く
  3D のリズムゲームと、その譜面を作るための専用エディターです。

  このエディターでは、次の 4 つを 1 つの画面の中でできます。
    ・ノーツを置く
    ・演出（速さが変わる・逆走 など）を付ける
    ・カメラの動きを決める
    ・本番のゲームで、すぐ遊んで確かめる

  目標は「譜面を作るのはプランナー。プログラムを触らなくても、
  誰でも譜面と演出が作れること」です。

 2. エディターでできること
==============================================================================

 ■ 置く・直す
   ・1 クリックでノーツを置く（その拍のグリッドに自動で吸着）
   ・ノーツの種類を絵で選ぶ
       タップ / ロング / フリック（右・左）/ トレース
       （1〜5 キーでも切り替え）
   ・ドラッグで時刻・レーンを動かす。ロングは終わりをドラッグで長さを変える
   ・途中で別のレーンへ曲がるロング（曲がり点）

 ■ 選ぶ・まとめて直す（M）
   ・投げ縄で囲んで選ぶ。ロングは胴が少しでも入れば選ばれる
   ・選んだノーツをドラッグで、まとめて動かす
       時間はグリッド 1 マスずつ、レーンも横に動く
       ほかのノーツと重なると赤くなり、離すと元に戻る
   ・Ctrl+C / Ctrl+X / Ctrl+V でコピー・切り取り・貼り付け
       マウスの所に貼れる。左右反転して貼ることもできる
   ・Delete で消す、Ctrl+A で全部選ぶ

 ■ 決まった形をまとめて置く（Pattern Tools）
   ・トリル、階段（上り・下り）、ジグザグ、連打、左右の手の交互、
     同時押し、ロングを押しながらトリル
   ・置く前に、マウスの所に半透明で形が出る（ゴースト）

 ■ 演出を「演出ノーツ」として置く（演出の窓）
   ・譜面の右の「演出の列」に、ノーツの形で置きます
   ・演出ノーツの頭が判定ラインを通った所で、演出が始まります
     尾（ロングのような長さ）の端で終わります
   ・本番の画面では、演出ノーツそのものは見えません

     逆走        ノーツが一度戻っていく。この先の譜面が判定円の下から
                 上がってきて見えるので、「次こう来る」と読める
     低速        ノーツと床の線がゆっくり流れる
     止める      一瞬止まる
     速くする    速く流れる
     下から戻る  見えているノーツが判定円の下に集まり、
                 勢いよく元の位置へ戻る。そのあとは普通に落ちてくる

   ・どの演出も見た目だけです。叩くタイミングは変わりません
     （曲に合わせて叩けば、必ず取れます）
   ・頭のドラッグで丸ごと動かし、尾の端のドラッグで長さを変えます

 ■ カメラ
   ・小節ごとにカメラの位置を決める
       プリセット：正面・低い・引き・高い・右・左・右上・左上
       ほかに、位置と見る先を数字で決める custom
   ・何拍かけて動くかも決められる

 ■ テストプレイ（F5）
   ・保存 → 本番のゲームを、今見ている小節の少し前から起動
   ・ゲームの画面は、エディターの真ん中にはめ込んで出る
   ・演出ノーツを選んでいる時の F5 は、その演出の所から
   ・オート（全部 PERFECT で流す）でも確かめられる

 ■ 音ズレ測定（音ズレ測定の窓）
   ・A：キーを押してから音が出るまでの遅れを測る
   ・B：メトロノームに合わせて叩き、人が感じるずれを測る
   ・音の鳴らし方を 3 つ比べられる
       XAudio2 / CRI ADX LE / 自分で作った WASAPI
   ・測った値を保存すると、ゲームの判定に使われる
     （プレイヤーは、ゲームの設定画面からも測り直せる）

 ■ そのほか
   ・ファイルの窓：譜面と曲を一覧からクリックで選ぶ（曲は wav / mp3）
   ・曲の再生は CRI ADX LE。実際に鳴っている音の時刻に合わせて譜面が進む
   ・譜面の横に曲の波形（音の大きさ）を表示
   ・窓はドッキングできる（タブで重ねる・好きな場所へ動かす）
   ・窓の背景に好きな絵を出せる（表示 → 窓の背景）
   ・保存すると、ゲームのフォルダにも譜面をコピー

 4. エディターの操作
==============================================================================

 ■ キー
   Ctrl+S          保存（ゲームのフォルダにもコピー）
   Ctrl+O          読み込み
   Space           再生 / 一時停止
   F5              テストプレイ（ここから）
   Shift+F5        テストプレイ（最初から）
   F2 / F3         2D の譜面 / 3D ビュー
   B               置くツール
   M               選ぶツール（投げ縄・まとめて動かす）
   1〜5            ノーツの種類
   Ctrl+C / X / V  コピー / 切り取り / マウスの所に貼る
   Delete          選んだノーツを消す
   Ctrl+A          全部選ぶ
   Esc             選ぶのをやめる
   ホイール・↑↓   譜面をスクロール

 ■ マウス（2D の譜面）
   左クリック                 ノーツを置く（置くツール）
   ノーツをドラッグ           動かす
   ロングの終わりをドラッグ   長さを変える
   右クリック                 ノーツを消す / 置くのをやめる

 ■ マウス（選ぶツール M）
   何もない所をドラッグ       投げ縄で囲んで選ぶ（Shift で足す）
   ノーツをクリック           そのノーツを選ぶ（Shift で選ぶ・外す）
   選んだノーツをドラッグ     まとめて動かす
   右クリック                 選ぶのをやめる

 ■ マウス（演出の列）
   種類を選んで列をクリック   演出ノーツを置く
   頭をドラッグ               丸ごと動かす
   尾の端をドラッグ           長さを変える
   右クリック                 消す


==============================================================================
 5. 譜面を作る流れ
==============================================================================

  1. ファイルの窓 → 曲 で、曲をクリック
  2. 設定の窓で BPM と offset（最初の拍が何秒か）を合わせる
     グリッドの線が曲の拍に重なれば OK
  3. Grid Tools で細かさ（4 分・8 分・16 分 …）を選ぶ
  4. 置くツール（B）で、ノーツをクリックで置いていく
     決まった形は Pattern Tools で、まとめて置く
  5. 選ぶツール（M）で、まとめて直す・コピーして別の所に貼る
  6. 演出の窓で種類を選び、演出の列にクリックで演出ノーツを置く
  7. 設定の窓のカメラの欄で、小節ごとのカメラを決める
  8. F5 で、本番のゲームですぐ確かめる → 直す → F5 … をくり返す
  9. Ctrl+S で保存（ゲームのフォルダにもコピーされる）


==============================================================================
 6. ゲーム（本番）について
==============================================================================

  エディターで作った譜面を遊ぶ、3D のリズムゲームです。
  奥から手前の判定ラインへノーツが流れてきます。

 ■ 操作
   タイトル     Enter               スタート
   曲選び       ← → / S F           曲を選ぶ
                Enter               決定
                Space               設定画面を開く・閉じる
                                    （明るさ・ハイスピード・タイミング）
                設定画面で Tab      タイミングをメトロノームで測る
                Tab                 オートの ON / OFF
   プレイ       S D F / J K L       左手 / 右手のレーン
                Tab                 ポーズ（ポーズ中に R でやり直し）
   どこでも     F11                 フルスクリーン
                Esc                 終了（確認なしで閉じます）

 ■ ノーツ
   タップ    判定ラインに重なった瞬間に、そのレーンのキーを押す
   ロング    押し始めて、終わりまで押し続ける
             途中で曲がるものは、移った先のキーに押し替える
   フリック  左右に動いて取る（左手のキーで左、右手のキーで右へ）

  ゲームの細かい遊び方は、README.txt（ゲーム版）にあります。

 7. フォルダの構成と、起動のしかた
==============================================================================

  3Dゲーム作成1\                 ゲーム（Sounder.sln）
    charts\                      譜面（*.json）
    assets\                      絵・音・モデル（assets\bgm に曲）
    shader\                      シェーダー
    audio_settings.json          音ズレ測定の結果（エディターが書く）
    player_settings.json         明るさ・ハイスピード・タイミング

  Direct3D Win32 Game1\          エディター（Direct3D Win32 Game1.sln）
    charts\                      エディター側の譜面
    asset\bgm\                   エディター側の曲
    asset\icons\                 ツールバーのアイコン
    cri\                         CRI ADX LE（ヘッダーとライブラリ）
    templates\                   演出のテンプレート（これから）

 ■ 動かすのに必要なもの
   Windows 10 / 11（64bit）、DirectX 11、Visual Studio 2022（x64）

 ■ 起動のしかた
   1. ゲーム（Sounder.sln）を x64 / Debug でビルドする
      テストプレイは、ゲームの x64\Debug\Sounder.exe を起動します
   2. エディター（Direct3D Win32 Game1.sln）を x64 でビルドして実行する
      ADX の DLL（cri_ware_pcx64_le.dll）は、ビルドの最後に自動でコピーされます
   3. ゲームの場所は、エディターの Game.cpp の kGameRoot で決めています
      別のパソコンで動かす時は、ここを直してください

 ■ うまく動かないとき
   ・テストプレイで変わらない
       → ゲームを Debug でビルドし直したか確かめる
         （エディターだけビルドしても、ゲームは古いまま）
   ・ファイルを入れ替えたのに変わらない
       → 「ビルド」ではなく「リビルド」
         （コピーしたファイルは日付が古く、ビルドされないことがある）
   ・窓がバラバラ
       → 表示 → 窓の並べ方を元に戻す

 8. 譜面ファイル（JSON）の中身
==============================================================================

  {
    "meta":         { "bpm": 160, "offset": 0.035, "audioFile": "w001.wav", ... },
    "notes":        [ { "lane": 0, "type": 0, "time": 1.5, ... }, ... ],
    "judgeCircles": [ { "lane": 0, "keyframe": [ { "time": 0, "x": ..., "y": ..., "z": ... } ] }, ... ],
    "camera":       [ { "fromMeasure": 10, "preset": "low", "blendBeats": 4 }, ... ],
    "gimmicks":     [ { "type": "speed", "start": 8.0, "end": 9.5, "easeIn": 0.5, "easeOut": 0.5, "speed": -1 },
                      { "type": "rise",  "start": 12.0, "end": 12.5, "from": -0.3 } ],
    "tracks":       [ ... ]
  }

  lane      0〜5（S D F J K L）
  type      0 タップ / 1 ロング / 2 右フリック / 3 左フリック / 4 トレース
  time      叩く時刻（秒）。ロングは終わりの時刻。押し始めは arrivalTime
  gimmicks  演出。start / end は秒、easeIn / easeOut は拍
              speed：1 = 普通、0.5 = 半分、0 = 止まる、マイナス = 逆走
              rise（下から戻る）：from は始まりの深さ（-0.3 = 判定円の少し下）
  tracks    レーンが流れてくる向き（奥・上・右・左）を小節ごとに

  エディターが知らない項目があっても、保存で消えずにそのまま残ります。

 9. 技術的に工夫したところ
==============================================================================

 ■ 速さの演出を「進んだ量」で作る
   ノーツの場所を「時刻の差」ではなく、「そのノーツまでに進んだ量の差」で
   決めています。進んだ量は、速さを積み重ねた値です
   （1/240 秒ごとの表を、読み込む時に作ります）。
   こうすると、低速・止める・速くする・逆走が全部同じしくみで動きます。
   しかも、叩く時刻には必ず判定円の上に来るので、判定がずれません。
   逆走の前に、後のノーツが判定円を素通りして見えてしまわないように、
   「この先の逆走で一度判定円を通り過ぎるノーツ」は、逆走が始まるまで隠しています。

 ■ 音ズレを数字で測って、判定に使う
   エディターに測定の部屋を作り、XAudio2・ADX・自作 WASAPI の
   遅れを同じやり方で比べられるようにしました。
   測った値はファイルに保存され、ゲームの判定の時刻に使われます。
   曲の時刻は、ADX の「実際に鳴った音に合わせた時刻」から取っています。

 ■ エディターの中で、本番のゲームを動かす
   F5 で本番のゲームを別のプロセスとして起動し、
   その窓をエディターの真ん中に重ねて表示しています。
   起動するときに、譜面の名前・始める秒・オートを渡します。

 ■ 投げ縄で選ぶ
   投げ縄の点は「画面の x と、時刻」で覚えています。
   こうすると、選んでいる途中でスクロールしても線がずれません。
   内側かどうかは、点から右へ伸ばした線が、辺を何回横切るかで調べます。
   まとめて動かすときは、毎フレーム「動かし始めた時の形」から
   ずらし直すので、何度行き来してもグリッドからずれません。

 ■ 保存しても消えない
   エディターが知らない項目（tracks など）を読み込み時に覚えておき、
   保存のときにそのまま書き戻します。


==============================================================================
 10. まだできていないこと
==============================================================================

  ・演出：分断（レーンが分かれる）、増殖、斬る、カメラの区間演出、
          出てくる場所の移動、テンプレート（w001 の最後の螺旋 など）
  ・何回でも戻せる Undo / Redo（今は、貼る・動かす・消すの 1 回分だけ戻せる）
  ・エディターの 2D の譜面に、速さの演出を反映した見た目を出す
  ・レーンの拡張（上・右・左から来るレーンを、エディターで置く）
