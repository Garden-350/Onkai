# フルコンボ画像を出す（プレイ中＋リザルト画面の両方）

## 前提

- 「フルコンボかどうか」の判定は前回作った`ChartObject::IsFullCombo()`をそのまま使います（JudgeSystemは関与しません）。
- 画像は`assets/texture/FULLCOMBO.png`という名前を想定しています。仮の画像を1枚作って、もうそのパスに置いておきました。気に入らなければ同じファイル名で好きな画像に差し替えてもらえればコード側は何も変えなくて大丈夫です。
- 表示の仕組みは、既存の`ComboHud`クラス（PERFECT/GREAT/GOOD/MISSやコンボ数のポップ演出を担当しているクラス）にそのまま相乗りさせます。プレイ中のポップアップも、こちらに追加します。

**変更前：**
```cpp

	m_ComboHud.Update(deltaTime);
```

**変更後：**
```cpp
	m_ComboHud.Update(deltaTime);

	// 曲が最後まで終わった瞬間、フルコンボが確定していたらポップアップを一度だけ出す

	}
```

## 画像について

`assets/texture/FULLCOMBO.png`に、仮の「FULL COMBO!」のプレースホルダー画像をもう置いておきました（送ったファイルと同じものです）。透過PNGで、金色の文字に紺の縁取りという簡単なものです。気に入らなければ、同じファイル名で好きな画像に差し替えてもらえれば、コード側は一切変更不要です。サイズも`SetScale`側で決まるので、元画像の解像度は気にしなくて大丈夫です。

## 確認してほしいこと

- プレイ画面側の表示位置（`SetPosition(0.0f, 0.0f, 0.0f)`＝画面中央）とサイズ（`SetScale(600, 150, 1)`）が、他のUIと被っていないか
- リザルト画面側の位置（`(0, 320, -5)`）も、ジャケット画像などと被っていないか
- 実際にフルコンボを達成したときだけ出て、ミスがあるときは出ないこと
