## 2. Init（ステージが始まるところで1回）

ChartObject::Init の最後などで呼ぶ。

```cpp
#include "ChargeAura.h"

ChargeAura::Instance().Init();
```

## 3. Update（毎フレーム。チャージしていない時も呼ぶ。発射後のフェードアウトに必要）

```cpp
float progress = 0.0f;
if (m_SpecialState == SpecialState::Charging)
    progress = (m_MusicTime - m_ChargeStartTime) / m_BarLength;   // 0～1
ChargeAura::Instance().Update(deltaTime, progress);
```

- チャージ小節に入った瞬間（拍にそろえた後）に `ChargeAura::Instance().Start();`
- 小節が終わってビームを撃つ瞬間に `ChargeAura::Instance().Release();`
- ポーズからのやり直しや曲の終わりでは `ChargeAura::Instance().Cancel();`

progress は「経過時間 ÷ 1小節の長さ」で、曲の時間から計算する。そのため、光の輪は必ず拍ぴったりに出る。

### 必殺技の処理ができる前に見た目だけ試す（仮。あとで消す）

```cpp
// ChartObject::Update の中
static bool  s_Test = false;
static float s_TestStart = 0.0f;
if (GetAsyncKeyState('C') & 1) { s_Test = true; s_TestStart = m_MusicTime; ChargeAura::Instance().Start(); }
float barLen = 60.0f / m_Bpm * 4.0f;
float prog = s_Test ? (m_MusicTime - s_TestStart) / barLen : 0.0f;
if (s_Test && prog >= 1.0f) { s_Test = false; ChargeAura::Instance().Release(); }
ChargeAura::Instance().Update(deltaTime, prog);
```

## 4. Draw（ここだけ注意）

描くのは「ステージ背景の直後、敵やレーンより前」。

```cpp
// 背景を描いた直後
ChargeAura::Instance().Draw(cam);
```

- 金の板が全画面を覆うので、敵より後に描くと敵が隠れる。
- ChargeAura::Draw の最後で `Renderer::ClearCurrentDepth()` を呼んでいる。これで、板が書いた深度のせいで後の敵やレーンが消えることはない。
- 背景をどこで描いているか分からなければ、`Game::Draw` の World パスの部分を貼ってほしい。置き場所を指示する。

## 5. ノーツが見えなくならないように

- 金の下地は、真ん中（レーンの後ろ）だけ暗い琥珀色にしてある。外側だけ派手にして、ノーツが見えにくくならないようにするため。
- レーンの下地が半透明なら、チャージ中だけ少し濃くすると安心。`ChargeAura::Instance().GetIntensity()`（0～1）を、レーン下地のアルファに足すだけでよい。
- チャージ中はレーンの線と判定ラインも金寄りにすると、フィーバー感が増す（fever_preview.gif 参照）。判定円はレーンの色のまま残す（キーの位置を見失わないため）。

### チャージノーツ（くの字）の見た目

比較は fever_note_options.png を参照。

- **B（白熱＋金の縁＋光）がおすすめ**。くの字の形は変えずに、次の3つを変える。
  - 本体の色を白に近いクリーム（255,250,232）にする。
  - 縁を金（255,176,30）にする。
  - 後ろに金のにじみ（光の板）を1枚置く。
- A（色だけ金）でも読みやすさは問題ない。B との差は「光っている感」だけなので、時間がなければ A でよい。
- D（向きを反転）は、判定の瞬間が「先端」から「両端」に変わるので、やめた方がよい。
- 色を変えるのは、必殺技を発動した瞬間。チャージ小節に入るノーツは発動前から画面の奥に見えているので、発動の瞬間にまとめて切り替える。

## 6. 調整したくなったら（ChargeAura.h の上の方の定数）

| やりたいこと | 定数 |
|---|---|
| もっと元の背景を透かしたい | `kBgAlpha` を 0.75 くらいにする |
| 集中線の中心を敵の方へ寄せたい | `kFocusY` を上げる |
| チラつきが強すぎる | `kLineSwap` を 0.08 にする |
| 輪をもっと大きく、ゆっくり | `kRingTo`、`kRingLife` |
| 光の帯の回転を速く／遅く | `kBurstSpin` |
| 光の帯をもっと濃く | `kBurstAlpha` |
| 拍のたびの明滅を強く | `kBeatFlash` |
