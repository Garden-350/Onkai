## 1. 直すと出てくる問題（できれば一緒に直す）

### 1-a. 少し早く押すとミスになる／押しっぱなしだと勝手に PERFECT

今の判定は「ノーツが届いた時刻より後に、その側のキーを押している（押しっぱなしでもよい）か」だけを見ている。

- 早めに押して、届く前に離す → ミス（早押しの猶予がない）
- その側のキーを押しっぱなしにしている（ロングを持っている等）→ 何もしなくても PERFECT

タップと同じく「このフレームで押したか」で、早い／遅いの両方に猶予を取るようにする。

### 1-b. 複数レーンにまたがるフリックでコンボが増えすぎる → フルコンボが出ない

JudgeFlickNotes は、lo〜hi のレーンごとに RegisterHit を呼んでいる。
3レーンにまたがるフリックだとコンボが +3 になるが、m_TotalNote ではフリックは 1 個として数えている。
IsFullCombo は `MaxCombo == m_TotalNote` で比べているので、そういうフリックがある譜面では全部 PERFECT でもフルコンボにならない。

OnJudge も3回呼ばれるので、敵へのダメージも3倍になっている。

コンボとダメージは1回だけにして、光やパーティクルだけをレーンごとに出すようにする。

### 1-c. 左右の向き

コードは「右フリック → requiredSide = -1（S/D/F 側）」になっている。
コメントは「右フリックなら1」で、コードと逆。
下のコードは「右フリック＝J/K/L（右手）」にしてあるので、実際に遊んで逆だと感じたら kRightFlickIsJKL を false にする。

```cpp
void JudgeSystem::JudgeFlickNotes(std::vector<ChartNote>& notes, float musicTime, int /*playerSide*/)
{
	// このフレームで、左手側(S/D/F)・右手側(J/K/L)のキーを新しく押したか
	bool pressed[2] = {
		Input::GetKeyTrigger(kLaneKeys[0]) || Input::GetKeyTrigger(kLaneKeys[1]) || Input::GetKeyTrigger(kLaneKeys[2]),
		Input::GetKeyTrigger(kLaneKeys[3]) || Input::GetKeyTrigger(kLaneKeys[4]) || Input::GetKeyTrigger(kLaneKeys[5]),
	};

	for (int side = 0; side < 2; side++)	// 0 = S/D/F側、1 = J/K/L側
	{
		if (!pressed[side]) continue;

		// その側で、判定時刻が一番近いフリックを1つだけ取る（1回押して2個取れないように）
		int best = -1;
		float bestDiff = 9999.0f;
		for (int i = 0; i < (int)notes.size(); i++)
		{
			const ChartNote& n = notes[i];
			if (n.judged || !n.IsFlick()) continue;
			int noteSide = (n.IsFlickRight() == kRightFlickIsJKL) ? 1 : 0;
			if (noteSide != side) continue;
			float diff = std::fabs(musicTime - n.time);	// 早くても遅くても同じ幅
			if (diff < bestDiff) { bestDiff = diff; best = i; }
		}
		if (best < 0 || bestDiff > kFlickGood) continue;

		int rank = (bestDiff < kFlickPerfect) ? 0 : (bestDiff < kFlickGreat) ? 1 : 2;
		HitFlick(notes[best], rank);
	}
}

// フリック成功：カウント・コンボ・ダメージは1回だけ。通過したレーンには光だけ出す
void JudgeSystem::HitFlick(ChartNote& n, int rank)
{
	int laneFrom = n.lane;
	int laneTo = (n.flickLaneTo >= 0) ? n.flickLaneTo : n.lane;
	int lo = std::min(laneFrom, laneTo);
	int hi = std::max(laneFrom, laneTo);

	if (rank == 0) m_Perfect++;
	else if (rank == 1) m_Great++;
	else m_Good++;

	RegisterHit(laneTo, rank);	// コンボ +1、OnJudge（ダメージ・判定表示）も1回
	for (int L = lo; L <= hi; L++)
	{
		if (L < 0 || L >= 6 || L == laneTo) continue;
		if (m_OnLaneEffect) m_OnLaneEffect(L);	// 光とパーティクルだけ
	}
	n.judged = true;
}
```
