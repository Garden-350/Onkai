# 演出その1「速さ」（逆走・低速・止める・速くする）組み込みガイド（11/17）

譜面の右に「演出の列」ができて、演出を**演出ノーツ**（頭＋ロングのような尾）として置けます。
頭が判定ラインを通った所で演出が始まり、尾の端で終わります。本番では演出ノーツは見えません。
F5 で本番のゲームがその小節から始まり、ノーツと床の拍の線が遅くなったり、止まったり、戻ったりします。
**判定の時刻は変わりません**（見た目だけ）。

## 入れ方

いつも通り、先にバックアップを取ってください。

### ゲーム（3Dゲーム作成1）
1. 新しいファイル：`Gimmick.h` `Gimmick.cpp` をフォルダに置く → VS の「ソース ファイル」を右クリック → 追加 → 既存の項目
2. 置き換え：`ChartLoader.h` `ChartLoader.cpp` `ChartObject.cpp` `NotePath.cpp` `JudgeLineGuide.cpp`
   - `JudgeLineGuide.cpp` は今までと同じ Shift-JIS のまま
3. **リビルド**（コピーしたファイルは日付が古いことがあるので、ビルドではなくリビルド）

### エディター（Direct3D Win32 Game1）
1. 新しいファイル：`ChartGimmicks.h` `ChartGimmicks.cpp` → 同じく 追加 → 既存の項目
2. 置き換え：`Game.cpp` `ChartExtras.cpp`
3. **リビルド**
4. 「演出」の窓が浮いて出たら：表示 → 窓の並べ方を元に戻す（右の窓とタブで並ぶ）

## 試し方（テスト用の譜面を置いてあります）
エディターとゲームの両方の `charts` に **`w001_gimmick.json`** を置きました（w001 のコピー ＋ 演出 4 つ）。

| 時刻 | 演出 | 見えるはずのこと |
|---|---|---|
| 8.0〜9.5 秒 | 逆走（-1） | 床の拍の線とノーツが奥へ戻る。この後のノーツが判定円の下から上がってきて、逆走が終わるとまた奥から来る |
| 16.0〜19.5 秒 | 低速（0.5） | ノーツと拍の線がゆっくりに。ノーツの間が詰まって見える |
| 30.0〜30.75 秒 | 止める（0） | 一瞬止まる |
| 44.5〜48.0 秒 | 速くする（2） | 速く来る。ノーツの間が広がる |

1. エディターの「ファイル」の窓 → `w001_gimmick` を開く
2. 譜面の右の細い列に演出ノーツが 4 つ出る（赤＝逆走、黄＝低速、灰＝止める、水色＝速くする）
3. 演出ノーツをクリック（または「演出」の窓の一覧をクリック）→ **F5** → その演出の小節（の 1 小節前）から始まる
4. 叩くタイミングは、演出があってもなくても曲どおりで取れることを確かめる

## 確かめること
- [ ] 演出の無い譜面（w001 など）は、今までとまったく同じ見た目
- [ ] 逆走：この後のノーツが下から上がってくる。逆走の前に、後のノーツが判定円を素通りしない
- [ ] 低速・止める・速くする：叩く時刻はずれない（PERFECT が出る）
- [ ] ロングの帯も同じ速さで動く
- [ ] エディター：種類のボタン → 列をクリックで 1 小節の演出ノーツ。頭のドラッグで丸ごと動く、尾の端のドラッグで長さ、右クリックで消える。Esc・ボタンをもう一度押す・何もない所の右クリックで置くのをやめる
- [ ] 保存 → 読み込みで演出が消えない。カメラや tracks も消えない

## 譜面の JSON
```json
"gimmicks": [
  { "type": "speed", "start": 8.0, "end": 9.5, "easeIn": 0.5, "easeOut": 0.5, "speed": -1.0 }
]
```
- start / end：秒（ノーツと同じ）
- easeIn / easeOut：拍。何拍かけて普通の速さから変わるか・戻るか
- speed：1＝普通、0.5＝半分、0＝止まる、マイナス＝逆走（-1 で同じ速さで戻る）

## 変えた所

### ゲーム
- **Gimmick.h / .cpp（新）**：速さの演出。`Scroll(t)`＝t 秒までにノーツが進んだ量（1/240 秒ごとの表）。`Progress`（今の進み具合）、`InView`（見えるか）、`PointVisible`（ロングの帯の 1 点が見えるか）
  - 逆走の前に、逆走の後のノーツが判定円を素通りして見えないように、「この先の逆走で一度判定円を通り過ぎるノーツ」は逆走が始まるまで隠す
  - 判定円より手前（下）は、逆走で上がってきている間だけ見せる（流れの長さの 35% まで：`kBelowLimit`）
- **ChartLoader**：`"gimmicks"` を読む（入り・抜けは拍 → 秒）
- **ChartObject.cpp**：LoadChart で `Gimmick::Load`。見えるかの判定（`m_MusicTime < st || m_MusicTime > et`）を `Gimmick::InView` に。進み具合を `Gimmick::Progress` に。ロングの帯（`LongPointAt` と `DrawHighwayLongNotes`）を「進んだ量」で。Uninit で `Gimmick::Clear`
- **NotePath.cpp**：タップ・ロングの進み具合を `Gimmick::Progress` で（フリックは今まで通り）
- **JudgeLineGuide.cpp**：拍の線も「進んだ量」で流す。逆走中は判定ラインより手前にも薄く出す

演出が無い譜面は、どの式も今までと同じ値になるようにしてあります。

### エディター
- **ChartGimmicks.h / .cpp（新）**：「演出」の窓（種類のボタン・一覧・選んだ演出の設定・警告・確認ボタン）、譜面の右の演出の列（演出ノーツ：頭＝始まり、尾＝終わり。置く・選ぶ・頭で丸ごと動かす・尾で長さ・右クリックで消す）、保存・読み込み
- **Game.cpp**：
  - `#include "ChartGimmicks.h"`
  - Render：`LatencyLab::DrawPanel` の後に `ChartGimmicks::DrawPanel`
  - DrawNoteEditorView：レーンとスペクトラムの間に演出の列（`kGimmickW = 34`）。`canvasHovered` の直後に `ChartGimmicks::DrawTimeline`（演出ノーツのドラッグ中・列の上では、普通のノーツを置かない）
  - SaveChart：`ChartGimmicks::Write`、LoadChart：`ChartGimmicks::OnLoad`
  - F5：演出を選んでいる時は、その演出の小節から
  - 最初の窓の並べ方に「演出」
- **ChartExtras.cpp**：`kKnownTop` に `"gimmicks"`（2 回書かないように）
