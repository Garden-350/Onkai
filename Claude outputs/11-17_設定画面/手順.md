# 曲選びの「設定」画面（枠組み）11/17

## できること
- 曲選びで **Space** → 設定の画面（後ろが暗くなって、一番手前に出る）。もう一度 **Space** で閉じる（閉じた時に保存）
- ↑↓ で項目、←→ で値（Shift を押しながらだと大きく動く）
  - 背景の明るさ：0〜100%（5% ずつ）※ 値を持っているだけ。ステージで使うのはこれから
  - スピード：0.1〜9.9（0.1 ずつ）。**曲選びの J / L から、ここに移した**
  - タイミング調整：−300〜+300 ms（1 ms ずつ、Shift で 10 ms）。**判定にすぐ効く**
- **TAB** → タイミングを測る：メトロノームに合わせて S D F J K L のどれかを押す（最初の 4 拍は練習、32 拍数える）→ Enter でその値にする / TAB でもどる
- 設定は `player_settings.json`（ゲームのフォルダ）に保存。次に起動しても残る
- エディターの「音ズレ測定」で保存し直すと（audio_settings.json の方が新しいと）、タイミングはそちらを取り込む

## ファイル
| ファイル | |
|---|---|
| 新規 PlayerSettings.h / .cpp | 設定の値（明るさ・スピード・タイミング）と、読み書き |
| 新規 SettingsOverlay.h / .cpp | 設定の画面（入力・描画・タイミングを測る）。PauseOverlay と同じ作り（Object の中に Texture2D を持つ） |
| 置き換え AudioSettings.h | 判定のずらしを PlayerSettings から取るようにした |
| 置き換え SelectScene.h / .cpp | Space で開く・開いている間は曲選びを止める・ハイスピの J / L と数字と絵を消した・起動時に保存したハイスピにする |
| 絵（こちらで置いた） | assets/settings/*.png（仮の絵。同じ名前・同じ縦横比で差し替えれば変わる） |
| 音（こちらで置いた） | assets/se/calib_metronome.wav（120BPM・1 秒無音・36 拍） |

## 入れ方
1. 新規 4 つをゲームのフォルダに置いて、プロジェクトに追加（PlayerSettings.cpp と SettingsOverlay.cpp を必ず）
2. AudioSettings.h・SelectScene.h・SelectScene.cpp を置き換え（git で差分を確認できる）
3. リビルド

## 確かめること
- [ ] 曲選びで Space → 設定が出る。Space で閉じる。開いている間は ←→ で曲が変わらない
- [ ] スピードを変えて閉じる → ステージのノーツの速さが変わる。起動し直しても残る
- [ ] タイミングを +50 にして遊ぶ → 遅めに押しても PERFECT になる（効いている）
- [ ] TAB → メトロノームが鳴る → 押すと光って回数が増える → 終わるとずれが出る → Enter でタイミング調整に入る
- [ ] 閉じたら曲のプレビューがまた鳴る
